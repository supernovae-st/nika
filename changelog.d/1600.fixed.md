- **The first parse refusals a newcomer meets teach the shape they
  refused.** A scalar `infer:`, `invoke:` or `agent:` body (`infer: "say
  hi"`, `invoke: nika:jq`) now reflects it into its mapping (`infer: {
  prompt: "say hi" }`, `invoke: { tool: nika:jq, args: { … } }`, or
  `invoke: { workflow: ./child.nika }` for a child workflow). An untyped
  `inputs:` entry names the typed form it meant (`topic: { type: string,
  default: "x" }`) and the ten primitives. A builtin written as a task key
  (`fetch:`) says it is called through `invoke: { tool: nika:fetch, args: {
  url: … } }`. The codes are unchanged (`NIKA-PARSE-019`, `NIKA-PARSE-005`).
