- **`nika check` no longer says a mock rehearsal dials nothing.** With
  `--model mock/echo`, the ACCESS row read `mock · never dials · nothing to
  judge` and a file with no `infer:` or `agent:` task read `access ready n/a ·
  nothing dials`, while its `nika:fetch` reached the network. The mock row now
  says `this model route never dials` and, under it, names the tasks whose own
  effects can still reach the network (a fetch or webhook to a real host, an
  MCP tool, a paid media call), judged on the PERMITS row; the moot line reads
  `access ready n/a · no model route` and names them the same way. `--json`
  lists them as `verdicts.network_tasks`, and the TUI's ACCESS READY reason
  no longer says `nothing dials`.
