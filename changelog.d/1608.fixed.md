- **A YAML syntax refusal (`NIKA-PARSE-001`) names its site and its usual
  cause.** `prompt: Note: this has a colon: here` and `infer: {prompt: ${{
  inputs.t }}}` printed one raw sentence with no line frame, and the `--json`
  finding had no span. The refusal now carries the position the YAML scanner
  stopped at, so `nika check` prints the `-->` frame with its caret and the
  `--json` parse finding carries `span: {start, end}` like a CONFORM finding
  (every span-bearing parse refusal does). A colon inside a plain value is
  told to quote the value or use a block scalar, and a bare `${{ … }}` inside
  a flow mapping is told to quote the expression.
