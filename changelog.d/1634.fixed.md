- **The container image also answers to the tag GitHub prints.** From the
  next release the train tags `ghcr.io/supernovae-st/nika:vX.Y.Z` on the
  same manifest as `X.Y.Z`, so the release tag copied from GitHub pulls
  instead of answering 404 (#1634). The alias is written only by the run
  that creates the version tag, before it, and is never moved: a failed
  alias leaves the version absent so a re-run retries, an equal alias is a
  no-op, and a divergent one refuses with no write. A replay of an already
  published train does not retag it, so `v0.120.0` and `v0.120.1` receive
  their alias through a separate publication act.
