- **A workflow the verifier doubts after an answer is written again, not left held.**
  An answer round replays the workflow and judges it, but never repairs
  it: when the verifier found it unfaithful, the session stopped with
  « built but not proposed » and asked for the request again. It now
  writes the workflow again under every answer already given, where the
  authoring round's own judgment and repairs run. A verifier that
  abstained or failed is not treated as a defect.
