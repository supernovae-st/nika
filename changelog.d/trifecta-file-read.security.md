- **`NIKA-SEC-009` follows untrusted content through a file a builtin reads.** A gate could clear the task that saved untrusted content to a file, and a later `nika:read` of that file then fed an ungated egress: the trifecta counted only an `exec:` as a reader of such files, so `nika check` passed the workflow. A builtin read (`nika:read`, `nika:grep`, `nika:glob`, `nika:edit`, a `nika:decide` bundle, the files `nika:image_fx`, `nika:chart` and `nika:image_generate` read, a `nika:fetch` multipart upload) of a path the earlier write may have reached now carries the content on, inline and inside a child workflow. Paths compare as written, folded and case-blind: a read of another literal path stays clean, a templated path may be any file.
