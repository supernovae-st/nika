# snippets · the yamls the website teaches, registered

Every yaml nika.sh renders must trace to a real file in this repo — that
law covers the smallest teaser as much as a 70-line job. This register
holds the files whose HOME is a website surface (the install page's
first files · the four-verb teaching set · the /learn destination file ·
even the 404 page's gag), not the curriculum path or the jobs shelf.

**In the corpus, out of the pack.** These files answer to
[`../CONVENTIONS.md`](../CONVENTIONS.md) like every file under
`examples/**` — checked green (`--native-strict`), honest permits,
run lines that work from the repo root. They are NOT in
`examples/manifest.yaml`: `nika try` stays the curated showroom, and
the projector's flat glob never reaches this directory. The conformance
CI walks it explicitly (`conformance/runner.py examples examples/snippets`).

One source, two readers: the website renders these bytes (its panel
strips nothing but the leading comment block) and links each panel's
`source ↗` here. Editing a snippet here IS editing the site's teaching.
