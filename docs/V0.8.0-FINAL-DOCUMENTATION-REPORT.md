## v0.8.0 Features Documented

### 1. Edit History (Undo/Redo) ✅
- **Keybindings:** Ctrl+Z (undo), Ctrl+Y (redo)
- **Coalescing:** 500ms intelligent grouping
- **Module:** `src/tui/edit_history.rs` (165 lines, 19 tests)
- **Documentation:** ARCHITECTURE.md, V0.8.0-STATUS.md

### 2. Session Persistence ✅
- **Storage:** `.nika/sessions/*.json`
- **Auto-save:** Every 30 seconds or on significant changes
- **Recovery:** Restore previous session on startup
- **Module:** `src/tui/session.rs` (312 lines, 13 tests)
- **Documentation:** ARCHITECTURE.md, V0.8.0-STATUS.md

### 3. Solarized Theme ✅
- **Three themes:** Dark (default), Light, Solarized
- **Keybinding:** Ctrl+T to cycle
- **Palette:** Ethan Schoonover's solarized colors
- **Scope:** Terminal + Studio TUI
- **Module:** `src/tui/theme.rs` (420 lines, 31 tests)
- **Documentation:** V0.8.0-STATUS.md, README.md

### 4. Config System ✅
- **File:** `~/.nika/config.toml`
- **Sections:** TUI, LLM, MCP, Logging, Editor
- **Format:** Type-safe TOML with serde
- **Hot reload:** Changes detected without restart
- **Modules:**
  - `src/core/config.rs` (280 lines)
  - `src/core/config_builder.rs` (145 lines)
  - Tests: 38 in config_test.rs
- **Documentation:** V0.8.0-STATUS.md, README.md
