## Feature Reference

### 5 Semantic Verbs

```
infer:   → LLM text generation (6 providers)
exec:    → Shell command execution
fetch:   → HTTP requests
invoke:  → MCP tool calls
agent:   → Multi-turn agentic loops
```

👉 See WORKFLOW-PATTERNS.md → "The 5 Verbs" for details

### Parallelism Features

```
for_each:           → Iterate over arrays with concurrency
spawn_agent:        → Nested agents with depth limits
decompose:          → Runtime DAG expansion
```

👉 See WORKFLOW-PATTERNS.md → "v0.8.0 New Features" for examples

### Data Flow

```
use: blocks         → Task-to-task binding
{{use.alias}}       → Template substitution
lazy: modifiers     → Deferred loading
?? defaults         → Fallback values
```

👉 See WORKFLOW-PATTERNS.md → "Data Binding" section

### LLM Providers (6)

```
claude    → Claude API via rig-core
openai    → OpenAI API via rig-core
mistral   → Mistral API via rig-core
groq      → Groq API via rig-core
deepseek  → DeepSeek API via rig-core
ollama    → Ollama local via rig-core
```

👉 See README.md → "Providers" section for details
