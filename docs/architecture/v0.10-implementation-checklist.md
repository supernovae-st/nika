## 3. DAG Layout Caching

**Purpose:** Scale to 500+ task DAGs, maintain 60fps

  - [ ] Define `CachedNode` and `CachedEdge`
  - [ ] Implement `ensure_layout()` (compute if dirty)
  - [ ] Implement `render()` (use cached data)
  - [ ] Add invalidation on DAG change

**Code Template:**
```rust
pub struct DagLayout {
    nodes: Vec<CachedNode>,
    edges: Vec<CachedEdge>,
    layout_hash: u64,
    dirty: bool,
}

impl DagLayout {
    pub fn ensure_layout(&mut self, graph: &FlowGraph) {
        if !self.dirty { return; }
        // Compute layout (O(V+E)) - only when DAG changes
        self.nodes = self.compute_node_positions(graph);
        self.edges = self.compute_edge_paths();
        self.dirty = false;
    }

    pub fn render(&self, area: Rect, buf: &mut Buffer) {
        // Render from cache (O(V+E) draw only)
        for edge in &self.edges {
            self.draw_edge(buf, edge);
        }
        // ... draw nodes
    }
}
```

## 4. Event Ring Buffer

**Purpose:** Bound memory usage, prevent unbounded growth

### Implementation Tasks

- [ ] **Create `src/event/ring_buffer.rs`** (60 lines)
  - [ ] Define `EventRingBuffer` with VecDeque
  - [ ] Implement `push()` with FIFO eviction
  - [ ] Implement `iter()` for widget consumption
  - [ ] Add configurable max size

**Code Template:**
```rust
pub struct EventRingBuffer {
    buffer: VecDeque<EventKind>,
    max_events: usize,
}

impl EventRingBuffer {
    pub fn push(&mut self, event: EventKind) {
        if self.buffer.len() >= self.max_events {
            self.buffer.pop_front();  // Drop oldest
        }
        self.buffer.push_back(event);
    }
}
```

- [ ] **Update `src/event/log.rs`**
