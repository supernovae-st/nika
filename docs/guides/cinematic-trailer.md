# Cinematic Trailer: Nika -- The Butterfly That Changes Everything

> 2-minute cinematic trailer
> Target audience: broad developer community, AI enthusiasts, open-source advocates
> Format: cinematic montage with narration, music, and visual effects
> Resolution: 4K, 24fps cinematic, letterboxed (2.39:1 aspect ratio)
> Music: orchestral build to electronic drop, inspired by tech product reveals

---

## Audio Design

**Music Arc:**
- 0:00-0:30: Minimal piano, sparse. A single repeated note. Tension.
- 0:30-0:50: Strings enter. Building. Arpeggiated synth underneath.
- 0:50-1:10: Full orchestra + electronic. The reveal moment.
- 1:10-1:40: Driving rhythm. Confident. Showcasing power.
- 1:40-2:00: Return to piano. Single note. Resolve. Silence. Title.

**Sound Design:**
- Keyboard typing sounds (mechanical, satisfying)
- Soft digital chimes on task completion
- A deep bass hit on the title reveal
- Data flow sounds (subtle digital pulses)
- Butterfly wing flutter (foley, very subtle)

## SEQUENCE 1: The Darkness (0:00 - 0:30)

### Shot 1 (0:00 - 0:05)

[CAMERA] Extreme close-up of a blinking cursor on a black screen. Shallow depth of field. The cursor pulses.

[SOUND] Single piano note, sustained. The cursor blink syncs with the note.

**Narration:** (whispered, intimate)
"Every revolution begins with a single line."

### Shot 2 (0:05 - 0:10)

[CAMERA] Pull back slowly to reveal a terminal. Lines of Python boilerplate scroll upward -- imports, class definitions, callback registrations. The text is slightly out of focus, suggesting confusion and overwhelm.

[SOUND] Piano note repeats. Strings begin to hum underneath.

**Narration:**
"We built towers of abstraction..."

### Shot 3 (0:10 - 0:15)

[CAMERA] Quick cuts between: a red error stack trace, a spinning loading indicator, a dependency tree diagram with hundreds of nodes, a memory usage graph climbing.

[SOUND] Each cut has a subtle percussive hit. Tension building.

**Narration:**
"...and called them frameworks."

### Shot 4 (0:15 - 0:20)

[CAMERA] Close-up of hands on a keyboard. The typing stops. Fingers lift away. A moment of stillness.

[SOUND] Strings swell gently. A breath of silence.

**Narration:**
"What if we started over?"

### Shot 5 (0:20 - 0:30)

[CAMERA] The dark screen begins to crack with light -- like dawn breaking through. Through the cracks, we see fragments of YAML syntax, clean and bright.

[SOUND] Piano melody begins. Simple, hopeful. A new theme.

**Narration:**
"What if a workflow engine respected your intelligence?"

## SEQUENCE 2: The Dawn (0:30 - 0:50)

### Shot 6 (0:30 - 0:35)

[CAMERA] Full screen. A `.nika.yaml` file appears, writing itself line by line:

```yaml
schema: nika/workflow@0.12

tasks:
  - id: dream
    infer:
      model: claude/claude-sonnet-4-20250514
      prompt: "Imagine something beautiful."
```

[ANIMATION] Each line appears with a subtle glow, as if being written by light itself. LSP completions flash briefly as each field appears.

[SOUND] Strings fully present now. Each line appearance has a soft chime.

**Narration:**
"Five verbs. One schema. Unlimited imagination."

### Shot 7 (0:35 - 0:40)

[CAMERA] The five verbs appear as floating text elements, arranged in a circle:

```
infer:    exec:    fetch:    invoke:    agent:
```

[ANIMATION] Each verb pulses with its own color -- infer in blue, exec in green, fetch in orange, invoke in purple, agent in gold. Lines connect them to the center, where the Nika butterfly forms.

[SOUND] Five distinct tones, one per verb, forming a chord.

**Narration:**
"Generate. Execute. Request. Connect. Orchestrate."

### Shot 8 (0:40 - 0:50)

[CAMERA] The YAML file from Shot 6 begins to transform. The text dissolves into flowing particles that rearrange into an architecture diagram -- AST phases, DAG nodes, executor branches. The diagram is alive, data flowing through it.

[SOUND] Full orchestral build. Electronic elements enter -- arpeggiated synth, subtle bass pulse.

**Narration:**
"Compiled. Validated. Parallelized. Before a single token is spent."

## SEQUENCE 3: The Power (0:50 - 1:10)

[ANIMATION] The TUI interface glows slightly, emphasizing its sophistication. Widget borders pulse.

[SOUND] Driving electronic rhythm begins. Confident, forward-moving.

[CAMERA] Cut to the Monitor view. A complex DAG with twelve nodes. Tasks begin executing -- nodes light up green one by one, then in parallel bursts. Progress bars fill. Token counters increment.

[ANIMATION] The DAG execution is time-compressed but rhythmic -- each completion synced to the music beat.

[SOUND] Each task completion gets a subtle hit in the rhythm track.

**Narration:**
"Forty-plus widgets. Three views. Mission control for AI."

[CAMERA] Split screen -- four panels showing four different workflows running simultaneously:

[ANIMATION] All four panels are active, showing real execution. Data flows between panels suggest interconnection.

[SOUND] Full-energy electronic track. Multiple layers.

### Shot 12 (1:05 - 1:10)

[CAMERA] The four panels merge into a single view: the full architecture diagram from the deep dive. But now it is rendered as a 3D structure, rotating slowly, with data particles flowing through every connection.

## Rendering Notes

- All terminal footage should be rendered at 4K even if displayed smaller
- The butterfly logo should have subtle particle effects when it appears
- Data flow animations should use additive blending for a luminous quality
- Color grading: cinematic teal-and-orange for dramatic sequences, warm neutral for code sequences
- Motion blur on quick cuts, sharp focus on code
- Letterbox bars should be true black (#000000)
- Final export: ProRes 4444 for master, H.265 for delivery
