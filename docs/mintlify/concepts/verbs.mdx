Five verbs. No sixth. Each has a narrow job and a typed contract.

<Note>
  The verb set is **closed**. Adding a sixth verb requires a schema version
  bump and the 12-gate admission process. We would rather say no.
</Note>

## `exec` — run a local command

```yaml
- id: build
  exec:
    cmd: cargo build --release
    cwd: ./crates/engine
    timeout: 300s
    env:
      RUSTFLAGS: "-C target-cpu=native"
```

What it does: spawn a subprocess. Capture stdout/stderr. Return exit code and output. Kills on timeout or parent drop.

**Invariants**:
- Always sets `kill_on_drop(true)` (no leaked processes)
- Concurrent pipe reading via `tokio::try_join!`
- Exit code ≠ 0 is a task failure by default (override with `allow_nonzero: true`)

## `fetch` — HTTP, URL, file, GitHub

```yaml
- id: pull_readme
  fetch:
    url: https://api.github.com/repos/supernovae-st/nika/readme
    headers:
      Accept: application/vnd.github.raw
    auth:
      bearer: ${env.GITHUB_TOKEN}
    timeout: 30s
    retry:
      max_attempts: 3
      backoff: 2.0
```

What it does: auto-detects URL type (HTTP, file://, github://, s3://) and routes to the right effect crate. Returns bytes or parsed JSON.

**Invariants**:
- Tainted output by default (external input = untrusted)
- Status code ≥ 400 is a failure (override with `allow_status:` list)
- Retries with exponential backoff

## `invoke` — built-in tool or MCP tool

```yaml
# Built-in
- id: extract_entities
  invoke:
    tool: text.extract_entities
    input:
      text: "{{ tasks.pull_readme.output }}"

# MCP server
- id: search_vectordb
  invoke:
    tool: mcp://chroma/query
    input:
      collection: nika_docs
      query: "{{ tasks.summarize.output }}"
```

What it does: calls one of 63 built-in tools (text processing, image manipulation, data transformation) or any MCP-compliant tool. Same verb, different tool routing.

## `infer` — LLM inference

```yaml
- id: summarize
  infer:
    provider: anthropic
    model: claude-opus-4-6
    prompt: |
      Summarize this in one sentence:
      {{ tasks.pull_readme.output }}
    structured:
      type: object
      properties:
        summary:
          type: string
          maxLength: 200
      required: [summary]
    max_tokens: 1000
    temperature: 0.3
```

What it does: unified API across 9 providers. Structured output validated against JSON Schema. Streaming supported via events.

**Invariants**:
- Single `InferRequest` shape regardless of provider
- Structured output uses native provider API where available (Anthropic tool use, OpenAI JSON mode, etc.)
- All providers emit the same event shape

## `agent` — loop with tools (ReAct)

```yaml
- id: investigate
  agent:
    provider: anthropic
    model: claude-opus-4-6
    system: |
      You are investigating a GitHub issue. Use the tools to gather
      context before answering.
    tools:
      - fetch
      - invoke
    max_iterations: 10
    budget:
      max_tokens: 100000
      max_wall_time: 120s
    task: |
      Investigate issue #{{ inputs.issue_number }} and summarize root cause.
```

What it does: multi-turn loop. Agent calls tools, observes results, iterates until done or budget exhausted. Returns final output plus full iteration trace in events.

**Invariants**:
- Budget hard-stops loop (tokens OR wall time, whichever first)
- Every tool call tainted-checked
- Iteration trace emitted as events for audit

## Why only five?

Because any workflow you can imagine decomposes into:
- **Do something locally** (`exec`)
- **Get data from the world** (`fetch`)
- **Use a tool** (`invoke`)
- **Ask a model** (`infer`)
- **Delegate to an agent** (`agent`)

Every other "verb" we considered was a special case of one of these.
