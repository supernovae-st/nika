## What you'll learn

- Declaring an agent with system prompt, tools, budgets
- Reading the iteration trace from events
- Bounding cost and time
- When to use `agent` vs. a scripted sequence of `infer`/`invoke`

## Stub example

```yaml
tasks:
  - id: investigate
    agent:
      provider: anthropic
      model: claude-opus-4-6
      system: "You investigate issues. Be concise."
      tools: [fetch, invoke]
      max_iterations: 10
      budget:
        max_tokens: 100000
        max_wall_time: 120s
      task: "Investigate issue #{{ inputs.issue_number }}"
```

the meantime.
