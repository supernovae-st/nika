Pattern for decomposing work:

1. **Plan**: use `infer` to produce a list of sub-tasks
2. **Fan out**: use `for_each` to process each in parallel
3. **Reduce**: use `infer` to merge results

```yaml
tasks:
  - id: plan
    infer:
      prompt: "Break '{{ inputs.goal }}' into 5 sub-tasks. Return JSON array."
      structured: { type: array, items: { type: string } }

  - id: process
    depends_on: [plan]
    for_each: "{{ tasks.plan.output }}"
    infer:
      prompt: "Handle sub-task: {{ item }}"

  - id: merge
    depends_on: [process]
    infer:
      prompt: "Merge these results: {{ tasks.process.outputs | json }}"
```
