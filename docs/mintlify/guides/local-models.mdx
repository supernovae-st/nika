Two paths for local inference:

## Ollama (HTTP daemon)

```yaml
- id: greet
  infer:
    provider: ollama
    model: llama3.2
    prompt: "Hi"
```

Runs against `http://localhost:11434` by default. Override with
`OLLAMA_HOST=https://...`.

## Native GGUF (in-process)

```yaml
- id: greet
  infer:
    provider: gguf
    model: file:///path/to/model.gguf
    prompt: "Hi"
```

Uses `mistral.rs` under the hood. No external process, no HTTP. Perfect for
airgapped runs.
