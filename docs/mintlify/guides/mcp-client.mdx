Nika is an MCP client. Point the `invoke` verb at any MCP server:

```yaml
tasks:
  - id: search
    invoke:
      tool: mcp://chroma/query
      input:
        collection: docs
        query: "{{ inputs.query }}"
```

Servers configured in `~/.config/nika/mcp.json` or inline in the workflow.
