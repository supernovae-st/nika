## The problem

Every provider has a different structured-output API:
- Anthropic → tool use with JSON Schema
- OpenAI → JSON mode or function calling
- Gemini → response schema
- Mistral → JSON object mode
- Ollama → JSON format flag
- GGUF local → grammar-constrained decoding

## The Nika promise

```yaml
- id: extract
  infer:
    provider: anthropic   # or openai, google, mistral, ...
    model: claude-opus-4-6
    prompt: "Extract three entities from this text: {{ inputs.text }}"
    structured:
      type: object
      properties:
        entities:
          type: array
          items: { type: string }
          minItems: 3
          maxItems: 3
      required: [entities]
```

Same workflow. Any provider. Output validated against the schema before it
ever reaches downstream tasks.
