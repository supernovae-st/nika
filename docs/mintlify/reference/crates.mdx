Nika is composed of ~40 Rust crates (we call them **organs**). Each passes
[12 gates](https://nika.sh/method) before admission. Here is the full inventory.

<Note>
  Numbers are grep-verified from the `nika-diamond` branch. Last updated: 2026-04-14.
  **5 of ~40 organs admitted.** 11,383 lines of src. 385 tests. 0 unwraps. 0 clippy warnings.
</Note>

## The seven layers

```
L5  ┃ BINARY         nika (composition root, <500 LOC)
L4  ┃ INTERFACES     cli · lsp · serve · sdk · init · lints · catalog-verify
L3  ┃ ORCHESTRATION  runtime · daemon
L2  ┃ DOMAIN         verb-exec · verb-fetch · verb-invoke · verb-infer · verb-agent
L1  ┃ EFFECTS        fs · http · process · blob · clock · crypto
L0.5┃ KERNEL         kernel (traits) · kernel-mock (test doubles)
L0  ┃ FOUNDATIONS    error · catalog · schema · binding · event · media-*
```

Strict downward dependencies only. No upward imports. Enforced by `cargo-deny`.

## The 12 gates (every organ must pass)

1. **SPEC** — `docs/crate-specs/nika-X.md` exists
2. **TDD** — tests written before implementation
3. **IMPL** — minimal, compiles, tests pass
4. **CLIPPY** — 0 warnings, `-D warnings`
5. **MUTATION ≥ 90%** — `cargo-mutants`
6. **PROPERTY** — `proptest` if security-sensitive
7. **BENCHMARKS** — if hot path
8. **DOCS** — `cargo doc --no-deps` 0 warnings
9. **CANARY E2E** — end-to-end test or documented exemption
10. **PARITY** — golden test vs legacy output
11. **REVIEW SWARM** — 3 parallel review agents
12. **ATOMIC COMMIT** — 1 organ = 1 commit
