Nika ships with **{STATUS.providers} LLM providers** in its catalog — frontier
labs, fast inference services, Chinese labs, enterprise platforms, and local
runners. Each provider is a TOML record describing its API dialect, authentication,
default and cheap models, capability tags, and per-model token limits.

## How to pick a provider

<Steps>
  <Step title="Pick your trust model">
    Cloud frontier (Anthropic / OpenAI / Google), open-weight hosted (Groq / Together / Fireworks / Cerebras), Chinese (Moonshot / Qwen / MiniMax / Zhipu), enterprise (Bedrock / Azure / Vertex), or local (native GGUF). Each has different residency and compliance trade-offs.
  </Step>
  <Step title="Check the `api_dialect`">
    `anthropic` and `gemini` have native dialects. `openai-chat` covers ~22 providers — same request shape, differing model names. `cohere`, `ai21`, `bedrock`, `voyage` are niche.
  </Step>
  <Step title="Verify env var is set">
    Each provider declares its `env_var` (e.g., `ANTHROPIC_API_KEY`). See the table below. `nika doctor` will check presence before run (once admitted).
  </Step>
  <Step title="Pick default vs cheap model">
    Every provider declares both. `default_model` is the capable tier; `cheap_model` is the cost-optimized tier. Capability rules in `model-capabilities.toml` determine which models support vision / tools / streaming / structured output.
  </Step>
</Steps>

## Example: invoke a provider

<CodeGroup>
```yaml workflow.nika.yaml (target design)
schema: nika/workflow@1
workflow: multi-provider

tasks:
  - id: primary
    infer:
      provider: anthropic
      model: claude-sonnet-4-20250514
      messages:
        - role: user
          content: "Explain linear algebra in one sentence."

  - id: fallback
    when: "{{ tasks.primary.failed }}"
    infer:
      provider: openai
      model: gpt-4o
      messages:
        - role: user
          content: "Explain linear algebra in one sentence."
```

```bash Required env
export ANTHROPIC_API_KEY=sk-ant-...
export OPENAI_API_KEY=sk-...
nika run workflow.nika.yaml
```
</CodeGroup>
