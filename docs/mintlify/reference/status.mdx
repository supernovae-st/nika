## What's crystal clear

These decisions are locked. Re-reading them is the authority chain.

- **40-42 crate target for v0.90** (confirmed by POST_AUDIT_REVISIONS 2026-04-14)
- **Layer invariants** — L0 zero I/O, L0.5 traits only, strict downward deps, `cargo-deny` enforced
- **12 gates per crate** — no exceptions, no partial admissions
- **No `.unwrap()` in `src/`** — `?` propagation everywhere, `workspace.lints.clippy.unwrap_used = "deny"`
- **Not an extraction** — every crate is written fresh, guided by legacy as reference
- **Forever v0.x** — no v1.0 target, quality over speed, 11-12 months
- **Test-first** — TDD, RED before GREEN, mutation testing ≥ 90% per crate

## What's being designed (not yet locked)

These areas need more thinking before the crate spec is written.

<AccordionGroup>
  <Accordion title="nika-schema — the biggest L0 crate (~12k LOC)">
    The AST parser, DAG builder, taint analysis, and `ariadne` diagnostics.
    The most complex crate in the constellation. Spec being drafted.

    Key questions still open:
    - How much of the legacy parser to preserve as reference vs rewrite completely
    - Whether taint should live in the AST or be a separate pass
    - `ariadne` vs `miette` for diagnostics (currently leaning `ariadne` for color)
  </Accordion>
  <Accordion title="nika-binding — template engine (~8k LOC)">
    Template expression parser, scope resolution, 64 pipe filters, type coercion.
    The legacy `mod.rs` was 7,243 LOC — the main reason for the diamond rewrite.

    Design decision: split into sub-modules (parser, resolver, filters) within the crate.
    The `#[non_exhaustive]` Filter enum is locked. Implementation TBD.
  </Accordion>
  <Accordion title="nika-verb-infer — provider routing (~4k LOC)">
    The unified `infer:` verb. Routes `InferRequest` to the right provider.
    Cross-provider structured output is shadow zone #2 — must be resolved here.

    The `api_dialect` field added in Phase D Session 2a is the foundation.
    Cross-provider proptest harness: 10k cases spec is locked.
  </Accordion>
  <Accordion title="Cortex v0.95 — memory subsystem (post-v0.90)">
    3 memory satellite crates: `nika-memory-oxigraph`, `nika-memory-embedding`,
    `nika-memory-fsrs`. Designed to plug into `nika-kernel`'s `MemoryStore` trait
    without breaking changes (forward-compat hooks already in `InferRequest`).

    Not starting until v0.90 is cut. Design lives in `project_nika_cortex_design.md`.
  </Accordion>
</AccordionGroup>
