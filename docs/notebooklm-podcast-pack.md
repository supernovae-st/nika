# PARTIE 4 — LA REPONSE : NIKA

## Le Logiciel

Un developpeur francais, Thibaut Melen, a regarde ce paysage et a pose une question heretique : et si les workflows d'IA pouvaient etre declares dans un fichier texte et executes depuis un seul binaire ?

Nika est un moteur de workflow YAML semantique pour taches IA. Ecrit en Rust — 451 000 lignes de code a travers 10 crates. Un seul binaire. Zero dependances. Pas de Python. Pas de Docker. Pas de cloud. Pas d'abonnement.

Cinq verbes decrivent n'importe quel workflow d'IA :

- infer : appeler n'importe quel LLM (22 fournisseurs, vision, sortie structuree)
- exec : executer des commandes shell (liste de blocage securitaire)
- fetch : requetes HTTP + 9 modes d'extraction (markdown, article, RSS, JSONPath...)
- invoke : appels d'outils MCP (43 outils integres + n'importe quel serveur MCP)
- agent : boucles autonomes multi-tours (garde-fous, limites de cout)

Voici un workflow complet :

```yaml
schema: "nika/workflow@0.12"
tasks:
  - id: scrape
    fetch: { url: "https://news.ycombinator.com", extract: article }
  - id: summarize
    with: { page: $scrape }
    infer: "Resume en 3 points: {{with.page}}"
```

Deux etapes. Zero lignes de code. Ca tourne sur un Raspberry Pi.

## Les Preuves

Les benchmarks ne mentent pas :

- Nika utilise 5 fois moins de RAM que LangChain (1 046 MB vs 5 706 MB)
- Demarrage a froid en 4 millisecondes (vs 62ms pour Python)
- CrewAI exclu des benchmarks : 44% de taux d'echec en production
- LangGraph : score de 0.85/100 dans les benchmarks AutoAgents. Rig (le moteur de Nika) : 90.06/100
- Nika : zero CVE connu. LangChain : CVE-2023-46229 avec score CVSS 9.3

Le secret : Rust. Pas parce que c'est a la mode. Parce que la performance EST l'accessibilite. Si ton outil a besoin de 2 GB de RAM, il ne tourne pas sur un laptop a 200 dollars. Si il met 8 secondes a demarrer, il ne tourne pas en CI. Un seul binaire qui va partout — c'est de la liberation, pas de l'optimisation.

AGPL casse ce pattern. Si tu modifies Nika et le fais tourner comme service, tu dois partager tes changements. Le code reste libre. La communaute garde le controle.
