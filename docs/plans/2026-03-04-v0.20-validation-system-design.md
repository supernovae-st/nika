# Nika DX Ecosystem Design v0.19-v0.24

> Transform Nika from "YAML config validated after the fact" to "real programming language with tooling like Rust/TypeScript"

## Vision

When writing a `.nika.yaml` workflow:

1. **IDE guides you** (like TypeScript) — real-time errors, red squiggly lines
2. **Autocompletion of EVERYTHING** — verbs, params, task IDs, templates, MCP tools
3. **Hover documentation** — inline docs for every key and value
4. **If `nika check` passes → `nika run` works** — guaranteed, no runtime surprises
5. **Claude generates correct workflows** — immediate validation feedback

### marked_yaml Integration

```rust
use marked_yaml::{parse_yaml, Node, Marker, Span};
use miette::{SourceOffset, SourceSpan, NamedSource, Diagnostic};

/// Convert marked_yaml Marker to miette SourceSpan
pub fn marker_to_span(source: &str, line: usize, column: usize, length: usize) -> SourceSpan {
    let offset = SourceOffset::from_location(source, line, column);
    SourceSpan::new(offset, length)
}

/// Parse YAML with span tracking
pub fn parse_with_spans(path: &str, content: &str) -> Result<Node, ParseError> {
    parse_yaml(0, content).map_err(|e| {
        ParseError {
            src: NamedSource::new(path, content.to_string()),
            span: extract_span_from_error(&e, content),
            message: e.to_string(),
        }
    })
}
```

### Debounced Validation

```rust
/// Validation worker with 50ms debouncing
pub async fn validation_worker(
    mut rx: mpsc::Receiver<ValidationRequest>,
    backend: Arc<NikaLspBackend>,
) {
    const DEBOUNCE_MS: u64 = 50;
    let mut pending: HashMap<Url, ValidationRequest> = HashMap::new();

    loop {
        tokio::select! {
            Some(req) = rx.recv() => {
                pending.insert(req.uri.clone(), req);
            }
            _ = tokio::time::sleep(Duration::from_millis(DEBOUNCE_MS)) => {
                let now = Instant::now();
                let ready: Vec<Url> = pending
                    .iter()
                    .filter(|(_, req)| now.duration_since(req.timestamp) >= Duration::from_millis(DEBOUNCE_MS))
                    .map(|(uri, _)| uri.clone())
                    .collect();

                for uri in ready {
                    if let Some(req) = pending.remove(&uri) {
                        let diagnostics = backend.validate_document(&req.content, &req.uri);
                        backend.client.publish_diagnostics(uri, diagnostics, Some(req.version)).await;
                    }
                }
            }
        }
    }
}
```

## Implementation Roadmap

### v0.19: Foundation (Two-Phase IR)

> **Prerequisite for all other layers** — This version transforms the AST from "parsed YAML" to "real programming language IR"

| Phase | Tasks | Deliverables |
|-------|-------|--------------|
| **1. marked_yaml migration** | Replace serde_yaml with marked_yaml | Span tracking for all nodes |
| **2. Raw AST module** | Create `ast/raw/` with Spanned<T> fields | raw::Workflow, raw::Task, etc. |
| **3. Analyzed AST module** | Create `ast/analyzed/` with interned IDs | analyzed::Workflow, TaskId(u32) |
| **4. Analyzer implementation** | raw → analyzed transformation + resolution | Symbol table, reference resolution |

**Estimated duration:** 3-4 weeks

**Key architectural changes:**

```rust
// BEFORE (v0.18)
pub struct Workflow {
    pub tasks: Vec<Task>,  // No spans, no resolution
}

// AFTER (v0.19)
// Phase 1: Parse YAML → raw::Workflow
pub mod raw {
    pub struct Workflow {
        pub tasks: Spanned<Vec<Spanned<Task>>>,  // With line:col
    }
}

// Phase 2: Analyze → analyzed::Workflow
pub mod analyzed {
    pub struct Workflow {
        pub tasks: IndexMap<TaskId, Task>,  // Interned, resolved
    }
    #[derive(Copy, Clone, Eq, PartialEq, Hash)]
    pub struct TaskId(u32);  // Efficient comparison
}
```
