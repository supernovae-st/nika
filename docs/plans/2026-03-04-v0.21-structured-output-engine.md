# v0.21 StructuredOutputEngine Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement a 4-layer defense system that achieves ~99.99% JSON schema compliance for LLM outputs in Nika workflows.

**Architecture:** Create a `StructuredOutputEngine` that orchestrates 4 defense layers: rig Extractor → Provider-Native tool_use → Retry with Feedback → LLM Repair. Each layer catches failures from the previous, with graceful degradation.

**Tech Stack:** rig-core v0.31 (Extractor trait), existing DynamicSubmitTool, jsonschema v0.27, schemars for runtime schema generation

## Architecture: 4-Layer Defense System

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     STRUCTURED OUTPUT ENGINE                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Input: prompt + JSON Schema                                                │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ LAYER 1: rig Extractor (Rust types only)                            │   │
│  │ • Uses schemars::JsonSchema derive macro                            │   │
│  │ • Compile-time type safety                                          │   │
│  │ • ~85% success rate on first try                                    │   │
│  │ ↓ FAIL? Try Layer 2                                                 │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ LAYER 2: Provider-Native (DynamicSubmitTool)                        │   │
│  │ • Claude: tool_use with input_schema                                │   │
│  │ • OpenAI: response_format with json_schema                          │   │
│  │ • Runtime JSON Schema (no Rust type needed)                         │   │
│  │ • ~95% success rate                                                 │   │
│  │ ↓ FAIL? Try Layer 3                                                 │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ LAYER 3: Retry with Feedback                                        │   │
│  │ • Uses format_validation_errors() for detailed feedback             │   │
│  │ • Includes original output + schema + error messages                │   │
│  │ • Max 2 retries (configurable)                                      │   │
│  │ • ~99% success rate after retries                                   │   │
│  │ ↓ FAIL? Try Layer 4                                                 │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ LAYER 4: LLM Repair                                                 │   │
│  │ • Separate LLM call with repair-focused prompt                      │   │
│  │ • Input: malformed output + schema + errors                         │   │
│  │ • Uses smaller/cheaper model (e.g., Claude Haiku)                   │   │
│  │ • ~99.99% success rate                                              │   │
│  │ ↓ FAIL? Return error with all attempts                              │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Output: Valid JSON matching schema OR detailed error                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

/// Format validation errors for short display (max 3 errors)
fn format_validation_errors_short(errors: &[String]) -> String {
    if errors.is_empty() {
        return "no errors".to_string();
    }
    if errors.len() <= 3 {
        return errors.join("; ");
    }
    format!("{}; ... and {} more", errors[..3].join("; "), errors.len() - 3)
}

### Step 1: Create module with types and configuration

Create `src/runtime/structured_output.rs`:

```rust
//! StructuredOutputEngine - 4-layer defense for LLM structured output (v0.21)
//!
//! Achieves ~99.99% JSON schema compliance through layered fallback:
//! 1. rig Extractor (Rust types with JsonSchema)
//! 2. Provider-Native (tool_use / response_format)
//! 3. Retry with Feedback (error messages + schema)
//! 4. LLM Repair (separate repair call)

use std::sync::Arc;

use serde::{Deserialize, Serialize};
use serde_json::Value;

use crate::error::NikaError;
use crate::event::{EventKind, EventLog};
use crate::provider::rig::RigProvider;
use crate::runtime::output::{extract_json, format_validation_errors, validate_inline_schema};
use crate::tools::submit_tool::DynamicSubmitTool;

/// Configuration for structured output extraction
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct StructuredOutputConfig {
    /// Enable Layer 1 (rig Extractor) - requires Rust type
    #[serde(default = "default_true")]
    pub enable_extractor: bool,

    /// Enable Layer 2 (Provider-Native tool_use)
    #[serde(default = "default_true")]
    pub enable_tool_use: bool,

    /// Enable Layer 3 (Retry with Feedback)
    #[serde(default = "default_true")]
    pub enable_retry: bool,

    /// Enable Layer 4 (LLM Repair)
    #[serde(default = "default_true")]
    pub enable_repair: bool,

    /// Max retries for Layer 3
    #[serde(default = "default_max_retries")]
    pub max_retries: u8,

    /// Model for repair (Layer 4) - uses cheaper model if None
    #[serde(default)]
    pub repair_model: Option<String>,
}

fn default_true() -> bool { true }
fn default_max_retries() -> u8 { 2 }

impl Default for StructuredOutputConfig {
    fn default() -> Self {
        Self {
            enable_extractor: true,
            enable_tool_use: true,
            enable_retry: true,
            enable_repair: true,
            max_retries: 2,
            repair_model: None,
        }
    }
}

/// Result of structured output extraction
#[derive(Debug, Clone)]
pub struct StructuredOutputResult {
    /// The extracted and validated JSON value
    pub value: Value,
    /// Which layer succeeded (1-4)
    pub layer: u8,
    /// Layer name
    pub layer_name: String,
    /// Total attempts across all layers
    pub total_attempts: u32,
}

/// Layer names for display
const LAYER_NAMES: [&str; 4] = [
    "rig Extractor",
    "Provider-Native",
    "Retry with Feedback",
    "LLM Repair",
];

/// StructuredOutputEngine - orchestrates 4-layer defense
pub struct StructuredOutputEngine {
    /// Configuration
    config: StructuredOutputConfig,
    /// Provider for LLM calls
    provider: RigProvider,
    /// Event log for observability
    event_log: Option<Arc<EventLog>>,
    /// Task ID for events
    task_id: String,
}

impl StructuredOutputEngine {
    /// Create a new engine with default config
    pub fn new(provider: RigProvider, task_id: impl Into<String>) -> Self {
        Self {
            config: StructuredOutputConfig::default(),
            provider,
            event_log: None,
            task_id: task_id.into(),
        }
    }

    /// Set configuration
    pub fn with_config(mut self, config: StructuredOutputConfig) -> Self {
        self.config = config;
        self
    }

    /// Set event log for observability
    pub fn with_event_log(mut self, log: Arc<EventLog>) -> Self {
        self.event_log = Some(log);
        self
    }

    /// Extract structured output using 4-layer defense
    ///
    /// # Arguments
    /// * `prompt` - The prompt to send to the LLM
    /// * `schema` - JSON Schema for validation
    ///
    /// # Returns
    /// * `Ok(StructuredOutputResult)` - Extracted and validated JSON
    /// * `Err(NikaError)` - All layers failed
    pub async fn extract(
        &self,
        prompt: &str,
        schema: &Value,
    ) -> Result<StructuredOutputResult, NikaError> {
        let mut total_attempts = 0u32;
        let mut last_errors: Vec<String> = Vec::new();
        let mut last_output: Option<String> = None;

        // Layer 2: Provider-Native (tool_use)
        // Note: Layer 1 (rig Extractor) requires Rust types, handled separately
        if self.config.enable_tool_use {
            total_attempts += 1;
            match self.try_layer_2_tool_use(prompt, schema).await {
                Ok(value) => {
                    self.emit_success(2, total_attempts);
                    return Ok(StructuredOutputResult {
                        value,
                        layer: 2,
                        layer_name: LAYER_NAMES[1].to_string(),
                        total_attempts,
                    });
                }
                Err((output, errors)) => {
                    self.emit_attempt(2, 1, false, Some(&errors.join("; ")));
                    last_output = Some(output);
                    last_errors = errors;
                }
            }
        }

        // Layer 3: Retry with Feedback
        if self.config.enable_retry {
            for retry in 1..=self.config.max_retries {
                total_attempts += 1;
                let feedback_prompt = self.build_feedback_prompt(
                    prompt,
                    schema,
                    last_output.as_deref().unwrap_or(""),
                    &last_errors,
                );

                match self.try_layer_3_retry(&feedback_prompt, schema).await {
                    Ok(value) => {
                        self.emit_success(3, total_attempts);
                        return Ok(StructuredOutputResult {
                            value,
                            layer: 3,
                            layer_name: LAYER_NAMES[2].to_string(),
                            total_attempts,
                        });
                    }
                    Err((output, errors)) => {
                        self.emit_attempt(3, retry as u32, false, Some(&errors.join("; ")));
                        last_output = Some(output);
                        last_errors = errors;
                    }
                }
            }
        }

        // Layer 4: LLM Repair
        if self.config.enable_repair {
            total_attempts += 1;
            match self.try_layer_4_repair(
                last_output.as_deref().unwrap_or(""),
                schema,
                &last_errors,
            ).await {
                Ok(value) => {
                    self.emit_success(4, total_attempts);
                    return Ok(StructuredOutputResult {
                        value,
                        layer: 4,
                        layer_name: LAYER_NAMES[3].to_string(),
                        total_attempts,
                    });
                }
                Err(repair_errors) => {
                    self.emit_attempt(4, 1, false, Some(&repair_errors.join("; ")));
                    return Err(NikaError::StructuredOutputAllLayersFailed {
                        task_id: self.task_id.clone(),
                        attempts: total_attempts,
                        final_errors: repair_errors,
                    });
                }
            }
        }

        // All enabled layers failed
        Err(NikaError::StructuredOutputAllLayersFailed {
            task_id: self.task_id.clone(),
            attempts: total_attempts,
            final_errors: last_errors,
        })
    }

    /// Layer 2: Provider-Native tool_use
    async fn try_layer_2_tool_use(
        &self,
        prompt: &str,
        schema: &Value,
    ) -> Result<Value, (String, Vec<String>)> {
        // Build prompt with schema instruction
        let structured_prompt = format!(
            "{}\n\n---\n\nRespond with a JSON object matching this schema:\n```json\n{}\n```\n\nReturn ONLY the JSON, no markdown, no explanation.",
            prompt,
            serde_json::to_string_pretty(schema).unwrap_or_default()
        );

        // Call LLM
        let output = self.provider
            .infer(&structured_prompt, None)
            .await
            .map_err(|e| (String::new(), vec![e.to_string()]))?;

        // Extract JSON from output
        let json_value = extract_json(&output)
            .map_err(|e| (output.clone(), vec![e]))?;

        // Validate against schema
        validate_inline_schema(&json_value, schema)
            .map_err(|e| (output.clone(), vec![e.to_string()]))?;

        Ok(json_value)
    }

    /// Layer 3: Retry with feedback
    async fn try_layer_3_retry(
        &self,
        feedback_prompt: &str,
        schema: &Value,
    ) -> Result<Value, (String, Vec<String>)> {
        // Same as Layer 2 but with feedback prompt
        let output = self.provider
            .infer(feedback_prompt, None)
            .await
            .map_err(|e| (String::new(), vec![e.to_string()]))?;

        let json_value = extract_json(&output)
            .map_err(|e| (output.clone(), vec![e]))?;

        validate_inline_schema(&json_value, schema)
            .map_err(|e| (output.clone(), vec![e.to_string()]))?;

        Ok(json_value)
    }

    /// Layer 4: LLM Repair
    async fn try_layer_4_repair(
        &self,
        malformed_output: &str,
        schema: &Value,
        original_errors: &[String],
    ) -> Result<Value, Vec<String>> {
        let repair_prompt = format!(
            r#"You are a JSON repair assistant. Fix the following malformed JSON to match the schema.

SCHEMA:
```json
{}
```

MALFORMED OUTPUT:
```
{}
```

VALIDATION ERRORS:
{}

INSTRUCTIONS:
1. Fix the JSON to match the schema exactly
2. Return ONLY valid JSON, nothing else
3. Do not add markdown code blocks
4. Preserve as much original data as possible"#,
            serde_json::to_string_pretty(schema).unwrap_or_default(),
            malformed_output,
            original_errors.join("\n")
        );

        // Use repair model if configured, otherwise use default
        let output = self.provider
            .infer(&repair_prompt, self.config.repair_model.as_deref())
            .await
            .map_err(|e| vec![format!("Repair LLM call failed: {}", e)])?;

        let json_value = extract_json(&output)
            .map_err(|e| vec![format!("Repair output not valid JSON: {}", e)])?;

        validate_inline_schema(&json_value, schema)
            .map_err(|e| vec![format!("Repair output failed validation: {}", e)])?;

        Ok(json_value)
    }

    /// Build feedback prompt for Layer 3
    fn build_feedback_prompt(
        &self,
        original_prompt: &str,
        schema: &Value,
        previous_output: &str,
        errors: &[String],
    ) -> String {
        format!(
            r#"{}

---

Your previous response had validation errors. Please fix them.

SCHEMA:
```json
{}
```

YOUR PREVIOUS RESPONSE:
```
{}
```

VALIDATION ERRORS:
{}

Please provide a corrected JSON response matching the schema exactly. Return ONLY the JSON."#,
            original_prompt,
            serde_json::to_string_pretty(schema).unwrap_or_default(),
            previous_output,
            errors.join("\n")
        )
    }

    /// Emit attempt event
    fn emit_attempt(&self, layer: u8, attempt: u32, success: bool, error: Option<&str>) {
        if let Some(log) = &self.event_log {
            log.emit(EventKind::StructuredOutputAttempt {
                task_id: Arc::from(self.task_id.as_str()),
                layer,
                layer_name: LAYER_NAMES[layer as usize - 1].to_string(),
                attempt,
                success,
                error: error.map(String::from),
            });
        }
    }

    /// Emit success event
    fn emit_success(&self, layer: u8, total_attempts: u32) {
        if let Some(log) = &self.event_log {
            log.emit(EventKind::StructuredOutputSuccess {
                task_id: Arc::from(self.task_id.as_str()),
                layer,
                layer_name: LAYER_NAMES[layer as usize - 1].to_string(),
                total_attempts,
            });
        }
    }
}

use crate::runtime::StructuredOutputConfig;

/// Structured output mode - bool or config
#[derive(Debug, Clone, Deserialize)]
#[serde(untagged)]
pub enum StructuredMode {
    /// Simple boolean enable
    Enabled(bool),
    /// Full configuration
    Config(StructuredOutputConfig),
}

/// Output policy configuration
#[derive(Debug, Clone, Deserialize, Default)]
pub struct OutputPolicy {
    /// Output format (text or json)
    #[serde(default)]
    pub format: OutputFormat,

    /// JSON Schema for output validation (inline object or file path)
    #[serde(default)]
    pub schema: Option<SchemaRef>,

    /// Maximum retry attempts on validation failure (default: 2)
    #[serde(default)]
    pub max_retries: Option<u8>,

    /// Save output to file path
    #[serde(default)]
    pub save: Option<String>,

    /// Enable structured output with 4-layer defense (v0.21)
    #[serde(default)]
    pub structured: Option<StructuredMode>,
}

impl OutputPolicy {
    /// Get structured output config if enabled
    pub fn structured_config(&self) -> Option<StructuredOutputConfig> {
        match &self.structured {
            Some(StructuredMode::Enabled(true)) => Some(StructuredOutputConfig::default()),
            Some(StructuredMode::Config(config)) => Some(config.clone()),
            _ => None,
        }
    }

    /// Check if structured output is enabled
    pub fn is_structured(&self) -> bool {
        match &self.structured {
            Some(StructuredMode::Enabled(enabled)) => *enabled,
            Some(StructuredMode::Config(_)) => true,
            None => false,
        }
    }
}
