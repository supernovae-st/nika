## 2. Crate Specifications

### 2.1 nika-core

**Purpose**: Pure types and AST, zero async dependencies. Publishable as standalone library.

| Metric | Value |
|--------|-------|
| **Target LoC** | ~30,000 |
| **Dependencies** | 8 (serde, thiserror, marked_yaml, strum, indexmap, serde_json, serde_yaml, regex) |
| **Features** | None (always compiles the same) |
| **Test Count** | 1,200 |
| **Coverage Target** | 85% |

**Public API**:
```rust
// nika-core/src/lib.rs
pub mod ast {
    pub mod raw {
        pub use crate::ast::raw::{parse, RawWorkflow, RawTask, RawTaskAction};
    }
    pub mod analyzed {
        pub use crate::ast::analyzed::{AnalyzedWorkflow, AnalyzedTask, TaskId};
    }
    pub mod analyzer {
        pub use crate::ast::analyzer::{analyze, AnalyzeResult, AnalyzeError};
    }
}

pub mod dag {
    pub use crate::dag::{Dag, DagNode, DagEdge, DagBuilder, validate_dag};
}

pub mod binding {
    pub use crate::binding::{UseEntry, BindingPath, LazyBinding};
}

pub mod source {
    pub use crate::source::{FileId, Span, Spanned};
}

pub use crate::error::{NikaError, NikaErrorCode, Result};
pub use crate::providers::{KNOWN_PROVIDERS, ProviderInfo, ProviderCategory};
pub use crate::models::{KNOWN_MODELS, ModelInfo, ModelFamily};
pub use crate::mcp_aliases::{MCP_ALIASES, McpAliasInfo};
```

### 2.2 nika-runtime

**Purpose**: Execution engine with async runtime. Requires tokio.

| Metric | Value |
|--------|-------|
| **Target LoC** | ~90,000 |
| **Dependencies** | 25+ (tokio, rig-core, rmcp, reqwest, etc.) |
| **Features** | `native-inference`, `spn-daemon` |
| **Test Count** | 2,700 |
| **Coverage Target** | 80% |

**Public API**:
```rust
// nika-runtime/src/lib.rs
pub use nika_core as core;  // Re-export for convenience

pub mod executor {
    pub use crate::executor::{TaskExecutor, TaskOutput, execute_task};
}

pub mod runner {
    pub use crate::runner::{WorkflowRunner, RunOptions, RunResult};
}

pub mod agent {
    pub use crate::agent::{AgentLoop, AgentParams, AgentResult, AgentTurnMetadata};
}

pub mod mcp {
    pub use crate::mcp::{McpClient, McpConfig, ToolCallRequest, ToolCallResult};
}

pub mod provider {
    pub use crate::provider::{RigProvider, InferResult};
    #[cfg(feature = "native-inference")]
    pub use crate::provider::native::NativeRuntime;
}

pub mod event {
    pub use crate::event::{EventLog, EventKind, WorkflowEvent};
}

pub mod binding {
    pub use crate::binding::{BindingResolver, resolve_bindings};
}

pub mod builtin {
    pub use crate::builtin::{BuiltinToolRouter, BUILTIN_TOOLS};
}

pub mod store {
    pub use crate::store::{DataStore, TaskResult};
}

pub mod secrets {
    pub use crate::secrets::{KeychainResolver, resolve_api_key};
}
```

```yaml
# .github/workflows/ci.yml
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup sccache
        uses: mozilla-actions/sccache-action@v0.0.6

      - name: Setup Rust
        uses: dtolnay/rust-toolchain@stable

      - name: Cache cargo registry
        uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/registry
            ~/.cargo/git
          key: ${{ runner.os }}-cargo-${{ hashFiles('**/Cargo.lock') }}

      - name: Cache target directory
        uses: actions/cache@v4
        with:
          path: target
          key: ${{ runner.os }}-target-${{ hashFiles('**/Cargo.lock') }}

      - name: Build workspace
        run: cargo build --workspace --release
        env:
          RUSTC_WRAPPER: sccache
          SCCACHE_GHA_ENABLED: "true"
```

## 9. Risk Mitigation

### 9.1 Risk Matrix

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Breaking external consumers | Medium | High | Maintain re-exports, semver |
| Circular dependencies | Low | High | Careful interface design, dependency inversion |
| Test migration issues | Medium | Medium | Run tests after each file move |
| CI/CD breakage | Medium | Medium | Matrix builds for each crate |
| Performance regression | Low | Medium | Benchmarks in CI |
| Compile time increase | Low | Low | Workspace caching, mold linker |

### 9.2 Rollback Strategy

If issues are discovered:

1. **Per-commit rollback**: Each commit is atomic and revertible
2. **Phase rollback**: Can revert entire phase via branch reset
3. **Full rollback**: Keep main branch untouched until final merge

### 9.3 Communication Plan

1. **Pre-migration**: Announce in CHANGELOG, GitHub issue
2. **During migration**: Update PR description with progress
3. **Post-migration**: Migration guide, updated docs
