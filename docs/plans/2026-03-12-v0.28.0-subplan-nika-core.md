## Overview

nika-core contains pure types and AST with zero async dependencies. It will be publishable as a standalone library for external consumers who want to parse/validate Nika workflows without the full runtime.

### Step 11: Finalize Public API

**Create final lib.rs**:
```rust
// nika-core/src/lib.rs
//! # nika-core
//!
//! Core types and AST for the Nika workflow engine.
//!
//! This crate provides:
//! - Two-phase AST parsing (Raw → Analyzed)
//! - DAG construction and validation
//! - Binding type definitions
//! - Provider and model static data
//!
//! ## Example
//!
//! ```rust
//! use nika_core::ast::raw::parse;
//! use nika_core::ast::analyzer::analyze;
//! use nika_core::source::FileId;
//!
//! let yaml = r#"
//! schema: nika/workflow@0.9
//! workflow: example
//! tasks:
//!   - id: hello
//!     infer: "Generate a greeting"
//! "#;
//!
//! let raw = parse(yaml, FileId(0)).unwrap();
//! let result = analyze(raw);
//! assert!(result.is_ok());
//! ```

#![forbid(unsafe_code)]
#![warn(missing_docs)]
#![warn(clippy::all)]
#![warn(clippy::pedantic)]

pub mod ast;
pub mod binding;
pub mod dag;
pub mod error;
pub mod mcp_aliases;
pub mod models;
pub mod providers;
pub mod source;

// Convenience re-exports
pub use error::{NikaError, NikaErrorCode, Result};
pub use providers::{KNOWN_PROVIDERS, ProviderInfo, ProviderCategory};
pub use models::{KNOWN_MODELS, ModelInfo, ModelFamily};
pub use mcp_aliases::{MCP_ALIASES, McpAliasInfo};

/// AST types for workflow parsing and analysis.
pub mod prelude {
    pub use crate::ast::raw::{parse, RawWorkflow, RawTask, RawTaskAction};
    pub use crate::ast::analyzed::{AnalyzedWorkflow, AnalyzedTask, TaskId};
    pub use crate::ast::analyzer::{analyze, AnalyzeResult};
    pub use crate::dag::{Dag, DagBuilder, validate_dag};
    pub use crate::source::{FileId, Span, Spanned};
    pub use crate::error::{NikaError, Result};
}
```

**Commit**: `feat(core): finalize lib.rs public API`
