## Overview

nika-tui contains the Terminal UI components built with ratatui. It includes the 4-view architecture, 37+ widgets, and theme system.

---

## Critical Task: App Struct Decomposition

The App struct with 34 fields must be decomposed into 5 subsystems:

| Subsystem | Fields | Responsibility |
|-----------|--------|----------------|
| ViewManager | 7 | current_view, previous, stack, view states |
| ChannelHub | 8 | event_tx/rx, mcp_tx/rx, workflow_tx/rx, shutdown |
| CacheManager | 6 | file_cache, schema_cache, trace_cache, mcp_tools, provider, config |
| ConfigManager | 5 | settings, theme, keybindings, project_root, config_path |
| LifecycleManager | 8 | startup, shutdown, mcp_connected, daemon, errors, tasks, jobs, session |
