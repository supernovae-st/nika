## Layer 1: Per-Commit Verification

### 1.1 Pre-Commit Hook Script

Create `.git/hooks/pre-commit`:

```bash
#!/bin/bash
set -e

echo "🔍 Pre-commit verification..."

# Quick format check (< 1 sec)
echo "  → Checking format..."
cargo fmt --all -- --check

# Type check (< 20 sec)
echo "  → Type checking..."
cargo check --workspace

# Clippy (< 30 sec)
echo "  → Running clippy..."
cargo clippy --workspace -- -D warnings

# Unit tests only (< 30 sec)
echo "  → Running unit tests..."
cargo test --workspace --lib -- --test-threads=4

echo "✅ Pre-commit verification passed!"
```

### 1.2 Commit Message Validation

Create `.git/hooks/commit-msg`:

```bash
#!/bin/bash
commit_msg=$(cat "$1")

# Validate conventional commit format
if ! echo "$commit_msg" | grep -qE "^(feat|fix|refactor|docs|test|chore|perf|style|ci)\("; then
    echo "❌ Commit message must follow format: type(scope): description"
    echo "   Types: feat, fix, refactor, docs, test, chore, perf, style, ci"
    echo "   Example: feat(core): extract AST module"
    exit 1
fi

# Require co-author
if ! echo "$commit_msg" | grep -q "Co-Authored-By:"; then
    echo "❌ Missing Co-Authored-By line"
    exit 1
fi

echo "✅ Commit message valid"
```

## Layer 2: Per-Phase Verification

### 2.1 Phase Verification Script

Create `scripts/verify-phase.sh`:

```bash
#!/bin/bash
set -e

PHASE=${1:-"current"}
echo "═══════════════════════════════════════════════════════════════"
echo "  PHASE $PHASE VERIFICATION"
echo "═══════════════════════════════════════════════════════════════"

# 1. Full build
echo ""
echo "📦 [1/7] Full workspace build..."
time cargo build --workspace --release
echo "✅ Build passed"

# 2. All tests
echo ""
echo "🧪 [2/7] Running all tests..."
time cargo test --workspace -- --test-threads=4
TEST_COUNT=$(cargo test --workspace 2>&1 | grep "test result" | tail -1 | grep -oE "[0-9]+ passed" | grep -oE "[0-9]+")
echo "✅ $TEST_COUNT tests passed"

# 3. Doc tests
echo ""
echo "📚 [3/7] Running doc tests..."
cargo test --workspace --doc
echo "✅ Doc tests passed"

# 4. Clippy
echo ""
echo "🔍 [4/7] Clippy analysis..."
cargo clippy --workspace -- -D warnings
echo "✅ Zero warnings"

# 5. Format check
echo ""
echo "🎨 [5/7] Format check..."
cargo fmt --all -- --check
echo "✅ Format correct"

# 6. Benchmarks (quick)
echo ""
echo "⚡ [6/7] Running benchmarks..."
cargo bench --workspace -- --quick 2>/dev/null || echo "No benchmarks defined yet"
echo "✅ Benchmarks complete"

# 7. Coverage (if tarpaulin installed)
echo ""
echo "📊 [7/7] Coverage analysis..."
if command -v cargo-tarpaulin &> /dev/null; then
    cargo tarpaulin --workspace --out html --skip-clean
    echo "✅ Coverage report generated: tarpaulin-report.html"
else
    echo "⚠️  cargo-tarpaulin not installed, skipping coverage"
fi

echo ""
echo "═══════════════════════════════════════════════════════════════"
echo "  PHASE $PHASE VERIFICATION COMPLETE ✅"
echo "═══════════════════════════════════════════════════════════════"
```

      matrix:

      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - uses: mozilla-actions/sccache-action@v0.0.6
      - name: Run tests
        run: cargo test --workspace
        env:
          RUSTC_WRAPPER: sccache
          SCCACHE_GHA_ENABLED: "true"

  clippy:
    name: Clippy
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy
      - run: cargo clippy --workspace -- -D warnings

    name: Coverage

    runs-on: ubuntu-latest
    strategy:
      matrix:
        crate: [nika-core, nika-runtime, nika-tui, nika]
