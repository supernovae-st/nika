# Plan: Smart CLI — v0.44.0 + v0.45.0

> Make `nika run` an intelligent assistant, not just a command executor.
> Two phases: UX polish (v0.44.0), power user (v0.45.0).

## Context

v0.43.0 shipped `-i/--input` and `--input-file`. The CLI now accepts runtime
overrides. This plan builds on that foundation with discoverability, interactivity,
preview, output capture, task filtering, and cost estimation.

**Key infrastructure already available:**
- `cliclack` in nika-cli (interactive prompts)
- `RunContext::iter_results()` — collect all task outputs after run
- `provider::cost::calculate_cost()` — full pricing tables for all 7 providers
- `dag::flow::compute_layers()` — topological ordering
- `DetailLevel::Json` — machine-readable output mode exists
- `Dag { adjacency, predecessors }` — full precedence graph

## Phase 1: v0.44.0 — Smart UX (~200 LOC)

### Task 1: Auto-discover workflows (`nika run` without args)

**File:** `nika/src/main.rs` — `Commands::Run` + `run_workflow()`

**Change:** Make `file` optional in the Run command:

```rust
Run {
    /// Path to .nika.yaml file (auto-discovered if omitted)
    file: Option<String>,
    // ... rest unchanged
}
```

**Logic in match arm (before calling `run_workflow`):**

```rust
let file = match file {
    Some(f) => f,
    None => {
        let workflows = discover_workflows(".").await?;
        match workflows.len() {
            0 => return Err(NikaError::ValidationError {
                reason: "No .nika.yaml files found. Try: nika init".to_string(),
            }),
            1 => {
                let path = &workflows[0];
                if !quiet {
                    eprintln!("  {} {}", "Auto-discovered:".dimmed(), path);
                }
                path.clone()
            }
            _ => {
                // Interactive picker (cliclack::select)
                pick_workflow(&workflows)?
            }
        }
    }
};
```

**New function `discover_workflows(dir)`:**

```rust
async fn discover_workflows(dir: &str) -> Result<Vec<String>, NikaError> {
    let mut entries = tokio::fs::read_dir(dir).await?;
    let mut found = Vec::new();
    while let Some(entry) = entries.next_entry().await? {
        let name = entry.file_name().to_string_lossy().to_string();
        if name.ends_with(".nika.yaml") {
            found.push(name);
        }
    }
    found.sort();
    Ok(found)
}
```

**New function `pick_workflow(workflows)` — interactive picker:**

```rust
fn pick_workflow(workflows: &[String]) -> Result<String, NikaError> {
    use std::io::IsTerminal;
    if !std::io::stdin().is_terminal() {
        return Err(NikaError::ValidationError {
            reason: format!(
                "Multiple .nika.yaml files found ({}). Specify one: nika run <file>",
                workflows.join(", ")
            ),
        });
    }
    // Use cliclack select
    let selected = cliclack::select("Which workflow?")
        .items(workflows.iter().map(|w| (w.clone(), w.clone(), "")).collect::<Vec<_>>())
        .interact()
        .map_err(|e| NikaError::ValidationError {
            reason: format!("Workflow selection cancelled: {}", e),
        })?;
    Ok(selected)
}
```

**Tests:**
- `discover_workflows` with temp dir: 0, 1, 2 files
- Non-TTY with multiple files → error

**Deps:** Add `cliclack` to `nika/Cargo.toml` (currently only in nika-cli).

### Task 2: Interactive input prompts (missing defaults)

**File:** `nika/src/main.rs` — inside `run_workflow()`, after merge

**Problem:** If an input has NO default value and NO CLI override, the workflow
crashes at template resolution with a cryptic error.

**Solution:** After merging CLI inputs, check for inputs without defaults and
prompt the user interactively.

**Detection:** An input without a default has a `type:` object form but no
`default` field, OR is explicitly `null`.

```rust
// After CLI input merge, before creating Runner
if std::io::stdin().is_terminal() {
    for (key, value) in &workflow.inputs {
        let has_value = match value {
            Value::Null => false,
            Value::Object(obj) => obj.contains_key("default"),
            _ => true, // shorthand form has value directly
        };
        if !has_value {
            let input = cliclack::input(format!("Enter value for '{}':", key))
                .interact_text()
                .map_err(|_| NikaError::ValidationError {
                    reason: format!("Input '{}' required but not provided", key),
                })?;
            workflow.inputs.insert(key.clone(), parse_input_value(&input));
        }
    }
}
```

**Skip if:** `--no-interactive` flag or stdin is not a TTY (pipes, CI).

**New flag:**
```rust
/// Skip interactive prompts (fail on missing inputs instead)
#[arg(long)]
no_interactive: bool,
```

### Task 4: `-o/--output` — capture results to file

**File:** `nika/src/main.rs` — `Commands::Run` + `run_workflow()`

**New flag:**
```rust
/// Save all task outputs to a JSON file
#[arg(short = 'o', long = "output", value_name = "FILE")]
output: Option<String>,
```

**Logic:** After `runner.run()` completes, collect all results and write JSON:

```rust
// After runner.run() succeeds
if let Some(ref output_path) = output {
    let results = runner.datastore().iter_results();
    let mut output_map = serde_json::Map::new();
    for (task_id, result) in &results {
        let mut task_obj = serde_json::Map::new();
        task_obj.insert("output".to_string(), (*result.output).clone());
        task_obj.insert("status".to_string(), json!(format!("{:?}", result.status)));
        task_obj.insert("duration_ms".to_string(), json!(result.duration.as_millis() as u64));
        output_map.insert(task_id.to_string(), Value::Object(task_obj));
    }
    let json = serde_json::to_string_pretty(&Value::Object(output_map))
        .map_err(|e| NikaError::ParseError { details: e.to_string() })?;
    tokio::fs::write(output_path, json).await?;
    if !quiet {
        eprintln!("  {} {}", "Output saved:".green(), output_path);
    }
}
```

**Problem:** `runner.run()` returns `Result<String, NikaError>` and consumes the
runner. We need access to `runner.datastore()` after `run()`.

**Check:** Does `Runner::run()` consume `self`? If so, we need `&mut self` or
the runner must expose the datastore before running. Let me verify at implementation
time — may need a `runner.datastore()` getter or collect results via the EventLog.

**Alternative approach if runner is consumed:** Use the EventLog which captures
all task results as events. Parse events after run to reconstruct output map.

### Task 6: `--task <id>` — run single task + deps

**File:** `nika/src/main.rs` + `nika-engine/src/runtime/runner.rs`

**New flag:**
```rust
/// Run only this task and its dependencies
#[arg(long, value_name = "TASK_ID")]
task: Option<String>,
```

**Approach:** Before creating the Runner, filter `workflow.tasks` to keep only
the target task and its transitive dependencies.

```rust
fn filter_tasks_for_target(
    workflow: &mut AnalyzedWorkflow,
    target_id: &str,
) -> Result<(), NikaError> {
    // 1. Find target task
    let target = workflow.tasks.iter()
        .find(|t| t.name == target_id)
        .ok_or_else(|| NikaError::ValidationError {
            reason: format!("Task '{}' not found in workflow", target_id),
        })?;

    // 2. Collect transitive dependencies (BFS)
    let mut required: HashSet<String> = HashSet::new();
    let mut queue: VecDeque<String> = VecDeque::new();
    required.insert(target_id.to_string());
    queue.push_back(target_id.to_string());

    while let Some(task_name) = queue.pop_front() {
        if let Some(task) = workflow.tasks.iter().find(|t| t.name == task_name) {
            for dep_id in &task.depends_on {
                let dep_name = workflow.task_table.get_name(*dep_id)
                    .unwrap_or("?").to_string();
                if required.insert(dep_name.clone()) {
                    queue.push_back(dep_name);
                }
            }
            for dep_id in &task.implicit_deps {
                let dep_name = workflow.task_table.get_name(*dep_id)
                    .unwrap_or("?").to_string();
                if required.insert(dep_name.clone()) {
                    queue.push_back(dep_name);
                }
            }
        }
    }

    // 3. Filter workflow.tasks to keep only required
    workflow.tasks.retain(|t| required.contains(t.name.as_str()));

    Ok(())
}
```

### Task 7: `--from <id>` — run from task onwards

**File:** Same as Task 6

**New flag:**
```rust
/// Run from this task onwards (skip earlier tasks)
#[arg(long, value_name = "TASK_ID")]
from: Option<String>,
```

**Approach:** Keep all tasks at or after the `from` task's DAG layer.

```rust
fn filter_tasks_from(
    workflow: &mut AnalyzedWorkflow,
    from_id: &str,
) -> Result<(), NikaError> {
    // 1. Compute layers
    let nodes: Vec<&str> = workflow.tasks.iter().map(|t| t.name.as_str()).collect();
    let edges = compute_edges(workflow);
    let depths = compute_layers(&nodes, &edges);

    // 2. Find from task's layer
    let from_layer = depths.get(from_id).ok_or_else(|| NikaError::ValidationError {
        reason: format!("Task '{}' not found in workflow", from_id),
    })?;

    // 3. Keep tasks at from_layer or deeper
    let keep: HashSet<&str> = depths.iter()
        .filter(|(_, &depth)| depth >= *from_layer)
        .map(|(&name, _)| name)
        .collect();

    workflow.tasks.retain(|t| keep.contains(t.name.as_str()));

    Ok(())
}
```

**Caveat:** Tasks before `from` that provide data via `with:` won't have results.
We should warn about this and suggest `--task` instead for single-task reruns.

### Task 8: Cost estimation before run

**File:** `nika/src/main.rs` — inside `run_workflow()`

**New flag:**
```rust
/// Confirm before running if estimated cost exceeds threshold (in USD)
#[arg(long, value_name = "USD", default_value = "0.10")]
cost_limit: f64,
```

**Logic:** Before running, estimate cost from task count * model pricing:

```rust
// After workflow is prepared, before runner.run()
let infer_count = workflow.tasks.iter()
    .filter(|t| t.action_type() == "infer" || t.action_type() == "agent")
    .count();

if infer_count > 0 && std::io::stdin().is_terminal() {
    let provider = workflow.provider.as_deref().unwrap_or("anthropic");
    let model = workflow.model.as_deref().unwrap_or("claude-sonnet-4-20250514");
    let avg_tokens = 2000u64; // rough estimate per task
    let est_cost = calculate_cost(
        ProviderKind::parse(provider).unwrap_or(ProviderKind::Claude),
        model,
        avg_tokens * infer_count as u64,
        avg_tokens * infer_count as u64,
    );

    if est_cost > cost_limit {
        eprintln!("  {} ~${:.4} ({} LLM tasks, {})",
            "Estimated cost:".yellow(), est_cost, infer_count, model);
        let confirm = cliclack::confirm("Continue?")
            .initial_value(true)
            .interact()
            .unwrap_or(false);
        if !confirm {
            return Err(NikaError::ValidationError {
                reason: "Cancelled by user".to_string(),
            });
        }
    }
}
```

## Non-Goals

- `nika run` without `tasks:` block (interactive task builder) — too complex
- Workflow chaining (`nika run a.yaml | nika run b.yaml`) — shell handles this
- Remote execution (`nika run --remote`) — future feature
- Dot notation inputs (`-i config.debug=true`) — too complex for V1
- Input validation (warn on unknown keys) — V2
- LSP migration — **already completed** (references, document_links, folding_ranges)
