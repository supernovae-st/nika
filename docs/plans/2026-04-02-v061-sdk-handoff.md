## PART 1: Rust SDK (`nika-sdk`)

### Architecture: Trait-Based Transport (NOT Enum)

Use `Box<dyn Transport>` instead of `enum Client { Remote, Embedded }`. This is extensible, testable, and feature-flag clean.

```
tools/nika-sdk/
├── Cargo.toml
└── src/
    ├── lib.rs           # Public API re-exports
    ├── client.rs        # Client struct, Job struct, Artifact struct
    ├── transport.rs     # pub(crate) Transport trait (sealed)
    ├── types.rs         # Event, JobInfo, JobResult, ArtifactInfo, RunOptions
    ├── error.rs         # SdkError
    ├── remote.rs        # #[cfg(feature = "remote")] — reqwest HTTP client
    ├── embedded.rs      # #[cfg(feature = "embedded")] — nika-engine Runner
    └── sse.rs           # SSE wire format parser (used by remote.rs)
```

### Transport Trait (Private, Sealed)

```rust
// src/transport.rs
#[async_trait::async_trait]
pub(crate) trait Transport: Send + Sync {
    async fn submit(&self, req: &RunRequest) -> Result<String, SdkError>; // returns job_id
    async fn status(&self, job_id: &str) -> Result<JobInfo, SdkError>;
    async fn cancel(&self, job_id: &str) -> Result<JobInfo, SdkError>;
    async fn events(&self, job_id: &str) -> Result<EventStream, SdkError>;
    async fn list_artifacts(&self, job_id: &str) -> Result<Vec<ArtifactInfo>, SdkError>;
    async fn download_artifact(&self, job_id: &str, name: &str) -> Result<bytes::Bytes, SdkError>;
    async fn health(&self) -> Result<bool, SdkError>;
}
```

### Client (Public API)

```rust
// src/client.rs
use std::sync::Arc;

pub struct Client {
    transport: Arc<dyn Transport>,
}

impl Client {
    #[cfg(feature = "remote")]
    pub fn remote(url: impl Into<String>, token: impl Into<String>) -> Result<Self, SdkError> {
        Ok(Self { transport: Arc::new(RemoteTransport::new(url.into(), token.into())?) })
    }

    #[cfg(feature = "embedded")]
    pub fn embedded() -> Result<Self, SdkError> {
        Ok(Self { transport: Arc::new(EmbeddedTransport::new()?) })
    }

    pub async fn submit(&self, workflow: &str, options: RunOptions) -> Result<Job, SdkError> {
        let job_id = self.transport.submit(&RunRequest {
            workflow: workflow.to_string(),
            inputs: options.inputs,
            resume_from: options.resume_from,
        }).await?;
        Ok(Job { job_id, transport: Arc::clone(&self.transport) })
    }

    pub async fn health(&self) -> Result<bool, SdkError> {
        self.transport.health().await
    }
}

pub struct Job {
    job_id: String,
    transport: Arc<dyn Transport>,
}

impl Job {
    pub fn job_id(&self) -> &str { &self.job_id }
    pub async fn status(&self) -> Result<JobInfo, SdkError> { self.transport.status(&self.job_id).await }
    pub async fn cancel(&self) -> Result<JobInfo, SdkError> { self.transport.cancel(&self.job_id).await }
    pub async fn events(&self) -> Result<EventStream, SdkError> { self.transport.events(&self.job_id).await }
    pub async fn artifacts(&self) -> Result<Vec<Artifact>, SdkError> { /* ... */ }

    /// Wait for completion by consuming the event stream.
    pub async fn wait(&self) -> Result<JobResult, SdkError> {
        use futures_util::StreamExt;
        let mut stream = self.events().await?;
        while let Some(event) = stream.next().await {
            match event? {
                Event::Completed { output, .. } => return Ok(JobResult { job_id: self.job_id.clone(), output }),
                Event::Failed { error, .. } => return Err(SdkError::Engine { message: error.unwrap_or_default(), code: None }),
                Event::Cancelled { .. } => return Err(SdkError::Engine { message: "cancelled".into(), code: None }),
                _ => continue,
            }
        }
        Err(SdkError::StreamClosed)
    }
}
```

### Error Type

```rust
// src/error.rs
#[derive(thiserror::Error, Debug)]
pub enum SdkError {
    #[error("invalid URL: {0}")]
    InvalidUrl(String),
    #[error("HTTP error {status}: {message}")]
    Http { status: u16, message: String, body: Option<String> },
    #[error("connection failed: {0}")]
    Connection(String),
    #[error("request timeout after {0:?}")]
    Timeout(std::time::Duration),
    #[error("engine error: {message}")]
    Engine { message: String, code: Option<String> },
    #[error("job not found: {0}")]
    NotFound(String),
    #[error("server queue full")]
    QueueFull,
    #[error("invalid workflow: {0}")]
    InvalidWorkflow(String),
    #[error("authentication failed")]
    Unauthorized,
    #[error("event stream closed unexpectedly")]
    StreamClosed,
    #[error("event deserialization failed: {0}")]
    EventParse(String),
    #[error(transparent)]
    Other(#[from] Box<dyn std::error::Error + Send + Sync>),
}
```

Key: **No `#[from] NikaError`**. Conversion is explicit in `embedded.rs`. **No `#[from] reqwest::Error`**. Conversion is explicit in `remote.rs`. SDK types never leak internal dependencies.

### Event Type (SDK-Owned, Decoupled from ServeEvent)

```rust
// src/types.rs
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
#[serde(tag = "type")]
pub enum Event {
    #[serde(rename = "started")]
    Started { job_id: String },
    #[serde(rename = "task_start")]
    TaskStart { job_id: String, task_id: String, verb: String },
    #[serde(rename = "task_complete")]
    TaskComplete { job_id: String, task_id: String, duration_ms: u64 },
    #[serde(rename = "task_failed")]
    TaskFailed { job_id: String, task_id: String, error: String, duration_ms: u64 },
    #[serde(rename = "artifact_written")]
    ArtifactWritten { job_id: String, task_id: String, path: String, size: u64 },
    #[serde(rename = "completed")]
    Completed { job_id: String, output: Option<String> },
    #[serde(rename = "failed")]
    Failed { job_id: String, error: Option<String> },
    #[serde(rename = "cancelled")]
    Cancelled { job_id: String },
}

pub type EventStream = std::pin::Pin<Box<dyn futures_util::Stream<Item = Result<Event, SdkError>> + Send>>;
```

JSON wire format is identical to ServeEvent (`#[serde(tag = "type")]`), so SSE data deserializes directly.

### RunOptions (Struct + Fluent Setters, NOT Builder)

```rust
#[derive(Debug, Clone, Default)]
pub struct RunOptions {
    pub inputs: Option<serde_json::Value>,
    pub resume_from: Option<String>,
}

impl RunOptions {
    pub fn new() -> Self { Self::default() }
    pub fn with_inputs(mut self, inputs: serde_json::Value) -> Self { self.inputs = Some(inputs); self }
    pub fn with_resume(mut self, job_id: impl Into<String>) -> Self { self.resume_from = Some(job_id.into()); self }
}
```

### SSE Parser (Critical for Remote Transport)

Parse `event:\ndata:\n\n` wire format into typed Event values. The SSE stream from nika serve:
- Uses `event: <type>` for event type
- Uses `data: <json>` for payload
- Keepalive: `: ping\n\n` (comment, discard)
- Terminal events end the stream
- No `Last-Event-ID` support (reconnect replays terminal state)

### Engine API for Embedded Transport

```rust
// Minimum embedded workflow:
let yaml = tokio::fs::read_to_string(path).await?;
let base_path = path.parent().unwrap().to_path_buf();
let analyzed = nika_engine::ast::parse_analyzed_with_includes(&yaml, &base_path)?;

let (event_log, event_rx) = nika_event::EventLog::new_with_broadcast();
let cancel_token = tokio_util::sync::CancellationToken::new();

let mut runner = nika_engine::runtime::Runner::with_event_log(analyzed, event_log)?
    .quiet()                              // REQUIRED: disables CLI renderer (makes Runner Send)
    .with_base_path(base_path)
    .with_cancel_token(cancel_token);

// For resume: inject checkpoints
for (task_id, value) in checkpoints {
    runner = runner.with_initial_context(&task_id, value);
}

let output = runner.run().await?;          // &mut self, single use
let results = runner.datastore().iter_results();  // post-run access
```

**Key constraints:**
- Runner is Send ONLY when `.quiet()` is called (removes `Box<dyn Renderer>` which isn't Sync)
- `run()` takes `&mut self` — single use per Runner
- `parse_analyzed(yaml)` works from strings (no file I/O needed)
- `event_log()` available after `run()` for artifact extraction

### Key napi-rs Patterns

**Async:** Use `async fn` directly — returns Promise to JS automatically:
```rust
#[napi]
impl Client {
    #[napi]
    pub async fn submit(&self, workflow: String, options: Option<RunOptions>) -> Result<Job> {
        // Rust async → JS Promise automatically
    }
}
```

**Streaming:** Use `AsyncGenerator` for `for await...of`:
```rust
#[napi(async_iterator)]
pub struct EventStream { /* ... */ }
```

Or `ReadableStream` via `web_stream` feature for Web Streams API compatibility.

**TypeScript:** Enable `type-def` feature on `napi-derive` — `.d.ts` auto-generated from Rust types.

**Testing:** Use `noop` feature for `cargo test` compatibility. JS tests with ava or jest.

**Publishing:** `napi` section in package.json declares platform targets. CI builds per-platform `.node` binaries. Auto-generated `index.js` handles platform detection.

### Implementation Notes

- **Remote mode ONLY** for v0.61.0 (no embedded — linking nika-engine into Node binary is too heavy)
- Wraps the Rust SDK's `RemoteTransport` directly
- SSE parsing reused from nika-sdk crate
- Nicolas (nk-jungo) is the primary consumer — **highest priority SDK**

### Target API

```typescript

const client = new Client('http://localhost:3000', process.env.NIKA_TOKEN);
```

### Key PyO3 0.24 Patterns

**Native async** (no pyo3-asyncio needed since 0.22):
```rust
#[pymethods]
impl Client {
    async fn submit(&self, workflow: String, inputs: Option<PyObject>) -> PyResult<Job> {
        // GIL released automatically while awaiting
    }
}
```

**Async generators** for streaming:
```rust
#[pyclass]
struct EventStream { rx: Arc<Mutex<mpsc::Receiver<Event>>> }

#[pymethods]
impl EventStream {
    fn __aiter__(slf: PyRef<'_, Self>) -> PyRef<'_, Self> { slf }
    async fn __anext__(&self) -> PyResult<PyObject> {
        match self.rx.lock().await.recv().await {
            Some(event) => Ok(event.into_py()),
            None => Err(PyStopAsyncIteration::new_err(())),
        }
    }
}
```

**Custom exceptions:**
```rust
create_exception!(nika_sdk, NikaError, PyException);
create_exception!(nika_sdk, WorkflowError, NikaError);
create_exception!(nika_sdk, TimeoutError, NikaError);
```

**Tokio runtime:** Global `OnceLock<Runtime>`, release GIL with `py.allow_threads()` for sync methods.

**Publishing:** maturin + `abi3-py39` for one wheel per platform across all Python 3.9+.

### Target API

```python
from nika_sdk import Client

client = Client(base_url="http://localhost:3000", token="xxx")

# Sync
result = client.run_sync("pipeline.nika.yaml", inputs={"topic": "AI"})
print(result.output)

# Async
import asyncio
async def main():
    job = await client.submit("pipeline.nika.yaml", inputs={"topic": "AI"})
    async for event in job.events():
        print(event)
    result = await job.wait()

asyncio.run(main())
```

## PART 4: HTTP API Reference (Complete)

### Authentication
- Header: `Authorization: Bearer <token>`
- `/health` is public (no auth)
- 401 on missing/invalid token (no body)

### Rate Limiting
- 10 req/s per token, burst 30
- 429 with `Retry-After` header on limit

### Endpoints

| Method | Path | Auth | Request | Response |
|--------|------|------|---------|----------|
| GET | `/health` | No | — | `{status, version, service}` |
| POST | `/v1/run` | Yes | `{workflow, inputs?, resume_from?}` | `{job_id, status}` |
| GET | `/v1/status/{id}` | Yes | — | `{job_id, status, workflow, timestamps, output}` |
| POST | `/v1/cancel/{id}` | Yes | — | `{job_id, status}` |
| GET | `/v1/events/{id}` | Yes | — | SSE stream (8 event types) |
| GET | `/v1/jobs/{id}/artifacts` | Yes | — | `{job_id, count, artifacts[]}` |
| GET | `/v1/jobs/{id}/artifacts/{name}` | Yes | — | Binary stream + ETag |
| GET | `/metrics` | Yes | — | Prometheus text |

### Error Format
All errors: `{"error": "message"}` with HTTP status 400/401/404/429/500/503.

### SSE Event Types
`started`, `task_start`, `task_complete`, `task_failed`, `artifact_written`, `completed`, `failed`, `cancelled`. Terminal events end the stream. Keepalive: `: ping` every 15s.

## PART 7: Constraints

1. **AGPL-3.0-or-later** — All crates must be AGPL
2. **No keychain popups** — `cargo test --workspace --lib` (always `--lib`)
3. **Runner is Send only with `.quiet()`** — always call `.quiet()` in embedded mode
4. **`run()` is single-use** — `&mut self`, create new Runner per execution
5. **Zero backward compat** — SDK is new, no legacy users
6. **Feature flags** — types always compile, transports are gated
7. **SDK types decoupled** — no `ServeEvent`, `NikaError`, or `reqwest::Error` in public API
