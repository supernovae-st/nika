## PHASE 1: SECURITY FIXES (~1h)

### 1.1 Exec blocklist — scan full command
**File**: `nika-engine/src/runtime/security.rs:437-447`
The `check_blocklist()` function limits scan to first 4096 bytes.
Fix: remove the `&cmd[..4096.min(cmd.len())]` limit, scan the entire command.
Test: create a command with 5KB padding before `sudo rm -rf /`, verify it's blocked.

### 1.2 shell:true injection — upgrade warn to error
**File**: `nika-engine/src/runtime/executor/exec.rs:51-71`
When `shell: true` and unescaped `{{with.*}}` detected, currently warns.
Fix: Return error NIKA-053 instead of warning. Force users to use `| shell` transform.
Test: workflow with `shell: true` + unescaped binding → NIKA-053 error.

### 1.3 BlockedCommand — redact command in error
**File**: `nika-engine/src/runtime/security.rs:483-486`
Fix: Apply `redact_for_event()` to the command stored in `BlockedCommand` error variant.
Test: verify blocked command error message doesn't contain API keys.

### 1.4 Read tool — file size pre-check
**File**: `nika-engine/src/tools/read.rs:128`
Fix: Check `fs::metadata(path)?.len()` before reading. Reject files > 50MB (or configurable).
Test: mock a large file, verify rejection with helpful error.
