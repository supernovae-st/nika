## S10 — MULTI-TENANT AUTH

### Overview

Replace single `NIKA_SERVE_TOKEN` with named API keys (BLAKE3-hashed, cached, auto-expiring).
**Schema**: V5 → V6 | **~850 LOC** | **10 TDD tests** | **8 modified + 2 new files**

### Architecture

```
Token Flow:
  nika serve token add --name "jungo-prod"
    → generate nk_<48hex> (raw token, shown ONCE)
    → BLAKE3 hash → store in serve_tokens table
    → startup: count_tokens() > 0 → AuthMode::MultiKey

  HTTP request:
    Authorization: Bearer nk_abc123...
    → BLAKE3(token) → DashMap cache lookup (60s TTL)
    → miss? → DB lookup → cache → Principal { token_id, name, role, scope }
    → inject into request extensions
    → rate limiter uses token_id (not raw token)
```

### Design Decisions (from blueprint)

- **BLAKE3** (not SHA-256): Faster, 32-byte output, same security
- **`nk_` prefix**: Log scanning + accidental commit detection
- **DashMap cache** with 60s TTL: Balances freshness vs DB load
- **AuthMode enum**: `Legacy { token }` vs `MultiKey { store }` — zero regression
- **Startup logic**: 0 tokens + no env = error, 0 tokens + env = legacy, >0 tokens = multi-key
- **Fire-and-forget `last_used_at`**: Non-blocking background tokio::spawn
- **Scope stored but not enforced** in L1 — forward-compatible for L2 glob matching

### V6 Schema

```sql
CREATE TABLE IF NOT EXISTS serve_tokens (
    id           TEXT PRIMARY KEY,     -- UUID v4
    name         TEXT NOT NULL UNIQUE, -- human-readable, 1-64 chars
    token_hash   BLOB NOT NULL UNIQUE, -- BLAKE3(raw_token), 32 bytes
    role         TEXT NOT NULL DEFAULT 'operator',
    scope        TEXT NOT NULL DEFAULT '*',
    created_at   TEXT NOT NULL,        -- RFC 3339
    expires_at   TEXT,                 -- RFC 3339 or NULL
    last_used_at TEXT,                 -- updated async
    revoked      INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX idx_serve_tokens_hash ON serve_tokens(token_hash);
CREATE INDEX idx_serve_tokens_name ON serve_tokens(name);
```

```rust
pub struct TokenEntry {
    pub id: String,
    pub name: String,
    pub token_hash: Vec<u8>,
    pub role: String,
    pub scope: String,
    pub created_at: String,
    pub expires_at: Option<String>,
    pub last_used_at: Option<String>,

    Legacy { token: String },
    MultiKey { store: TokenStore },

    pub token_id: String,
    pub token_name: String,
    pub role: String,
    pub scope: String,
}

    storage: Storage,
    ttl: Duration, // 60s default
}
```
