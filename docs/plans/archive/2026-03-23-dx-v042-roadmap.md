## PHASE 1: CUT THE NOISE (simplify)

### Task 1.1: Kill `nika setup` command

**Files:**
- Delete: `tools/nika-cli/src/setup.rs` (614 lines)
- Modify: `tools/nika/src/main.rs` — remove `Commands::Setup` variant
- Modify: `tools/nika-cli/src/lib.rs` — remove `pub mod setup`
- Move: `setup.rs:run_check()` → `doctor.rs` (as `--fix` action)

`nika setup` is redundant — auto-setup in `nika init` + `maybe_run_auto_setup()` covers everything. Doctor `--fix` handles repair. Delete the entire command.

### Task 1.2: Slim down `.nika/` init boilerplate

**Files:**
- Modify: `tools/nika-cli/src/init.rs`

Remove generation of:
- `.nika/memory.yaml` (empty, memory system not implemented)
- `.nika/policies.yaml` (empty, policy system not implemented)
- `.nika/user.yaml` (empty, user system not implemented)
- `.nika/proposed/` (empty dir, never used)
- `.nika/cache/` (empty dir, created on demand)
- `.nika/memory/` (empty dir, never used)

Keep:
- `.nika/config.toml` (essential)
- `.nika/agents/researcher.md` (useful example)
- `.nika/skills/code-review.md` (useful example)
- `.nika/context/project.md` (useful)
- `.nika/workflows/helpers.nika.yaml` (useful)

**Result:** 6 fewer files/dirs in every new project.

### Task 1.3: Hide power-user commands from --help

**Files:**
- Modify: `tools/nika/src/main.rs`

Add `#[command(hide = true)]` to:
- `Commands::Schema`
- `Commands::Features`
- `Commands::Workflow` (keep `nika graph` as top-level alias)
- `Commands::Lsp`

They still work, just not in default help. Cleaner first impression.

### Task 1.4: Simplify `nika new`

**Files:**
- Modify: `tools/nika-cli/src/new_cmd.rs`

Reduce to: `nika new <name> [--verb infer|exec|fetch|invoke|agent]`
Remove: `--wizard`, `--template`, `--with-mcp`, `--with-include`, `--with-artifacts`

## PHASE 2: AMPLIFY THE MAGIC (wow moments)

### Task 2.1: `nika` bare = live demo

**Files:**
- Modify: `tools/nika/src/main.rs` — the `None` (no subcommand) handler

1. Show version + tagline
2. Run a built-in 2-task DAG (exec: "echo" → exec: "echo")
3. Show the DAG visualization + timeline
4. Print "Try: nika init" at the end
