## DETAILED TASK PLANS

### Task M9: Cache ChatDagPanel (don't rebuild every frame)

**Root cause**: `render_dag_panel()` in `dag_panel.rs:26-55` creates a new `ChatDagPanel`, clones ALL nodes/edges into it, then renders. This happens 60x/sec.

**The trick**: ChatDagPanel is only invalidated when `sync_dag_from_messages()` is called (message data changes). Between syncs, the panel is identical.

**Implementation**:
1. Add field to ChatView (`mod.rs`):
   ```rust
   /// Cached DAG panel — rebuilt only when dag_nodes/dag_edges change
   cached_dag_panel: Option<ChatDagPanel>,
   ```
2. In `sync_dag_from_messages()` — set `self.cached_dag_panel = None` to invalidate
3. In `render_dag_panel()` — check cache:
   ```rust
   let dag_panel = if let Some(cached) = &self.cached_dag_panel {
       cached.clone()  // Cheap clone of already-built panel
   } else {
       let mut panel = ChatDagPanel::new().with_title("CHAT DAG");
       for node in &self.dag_nodes { panel.add_node(node.clone()); }
       for edge in &self.dag_edges { panel.add_edge(edge.clone()); }
       self.cached_dag_panel = Some(panel.clone());
       panel
   };
   ```
4. Still update selection + animation_tick on the cloned panel (cheap)

**Files**: `views/chat/mod.rs`, `views/chat/dag_panel.rs`
**Test**: `cargo test -p nika-tui --lib`

## WARNINGS & GOTCHAS

### Pre-commit Hook
The `.husky/pre-commit` hook runs `cargo clippy --all-targets --all-features -- -D warnings`. This compiles the LiveRenderer (committed WIP feature). If LiveRenderer code causes clippy errors, fix them with `#[allow]` attributes — don't fight the hook.

### Stash Artifacts
Previous session had `git stash pop` contamination from a LiveRenderer branch. If you see unexpected dirty files in:
- `tools/nika-engine/src/display/mod.rs`
- `tools/nika-engine/src/display/renderer.rs`
- `tools/nika-engine/src/runtime/runner.rs`
- `tools/Cargo.toml` / `tools/Cargo.lock`

Run `git checkout -- <file>` BEFORE starting work.

### macOS Keychain
**NEVER** run `cargo test` without `--lib`. Contract tests trigger macOS Keychain popups. Always use `cargo test --workspace --lib` or `cargo test -p <crate> --lib`.

### Error Code Collision
NIKA-160 is used by BOTH `ParseErrorKind::Syntax` (nika-core) AND `StartupError` (nika-engine). ARCH-3 must resolve this. Don't create new error codes in the 160-169 range.

### nika-core is Zero-I/O
nika-core must NEVER depend on tokio, reqwest, or any async runtime. It's pure data structures + serde. ARCH-5 (ContentBlock) was validated against this constraint. Any new types added to nika-core must follow the same rule.
