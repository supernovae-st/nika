Read `docs/plans/2026-03-26-nika-daemon-architecture.md` for the full design.

**Tasks:**
1. Create `tools/nika-daemon/` crate with server, client, protocol modules
2. Implement `DaemonServer` — tokio UnixListener, length-prefixed JSON IPC
3. Implement `DaemonClient` — connect/send/recv with timeout
4. `nika daemon start` — daemonize, PID file, socket, signal handling
5. `nika daemon stop/status` commands
6. Secrets service — sole keychain accessor, env var injection
7. `nika doctor` — add daemon health check
8. Integration: boot.rs Phase 4 uses DaemonClient if daemon running

**Key design decisions already made:**
- Single binary (`nika daemon start` forks itself)
- Unix socket at `~/.nika/daemon/nika.sock`
- PID file at `~/.nika/daemon/nika.pid`
- Wire format: 4-byte big-endian length + JSON
- `nix` crate for daemonize + signal handling
- Daemon is OPTIONAL — `nika run` works without it

### Phase 2: Job Scheduler

4. Cron scheduling: `nika job submit --cron "0 * * * *" workflow.nika.yaml`
5. Job execution: daemon spawns `nika run <workflow> --json-output` as child
6. Job history + output capture
