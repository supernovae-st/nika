### View Order (Option A — Explorer-First)

| # | View | Key | Purpose | Why This Order |
|---|------|-----|---------|----------------|
| 1 | **Explorer** | `1` / `e` | File browser + DAG preview | Entry point, VS Code style |
| 2 | **Chat** | `2` / `c` | AI agent conversation | Natural after finding file |
| 3 | **Editor** | `3` / `d` | YAML editing | Edit what you found |
| 4 | **Runner** | `4` / `r` | Execution monitor | Run what you edited |
| 5 | **Scheduler** | `5` / `s` | Cron/queue management | Advanced: schedule runs |
| 6 | **Settings** | `6` / `,` | Configuration | Always last |

### Chat-as-DAG Semantics

| Input Pattern | DAG Behavior | Example |
|---------------|--------------|---------|
| Normal message | Sequential (depends on prev) | `"Generate title"` → needs `msg-001` |
| `//` prefix | Fork (parallel/independent) | `"// Fetch trends"` → no dependencies |
| `@N` reference | Explicit dependency | `"Combine @1 @2"` → needs msg-001, msg-002 |
| `@last` | Reference last message | `"Improve @last"` → needs prev |
| `@all` | Fan-in all tasks | `"Summarize @all"` → needs all |

### Live DAG Features

- **Real-time updates**: Nodes appear as messages sent
- **Animated edges**: Pulsing line when data flowing
- **Fork visualization**: Branching arrows for `//` prefix
- **Fan-in visualization**: Converging arrows for multiple `@N` refs
- **Status colors**: Green (done), Yellow (running), Red (error)
- **Mini-map**: Zoom out for large DAGs (>10 nodes)

### YAML Preview Features

- **Auto-generated**: Built from chat messages in real-time
- **Syntax highlighted**: Verbs colored per taxonomy
- **Export button**: Save as `.nika.yaml` file
- **Comments preserved**: `# // fork` and `# @N fan-in` annotations
- **Schema header**: Always `nika/workflow@0.6`

### Input Commands (Verbs)

| Command | Verb | Example |
|---------|------|---------|

| `/exec` | `exec:` | `/exec npm run build` |

### Special Input Patterns

| Pattern | Effect |
|---------|--------|
| `//` prefix | Fork (parallel execution) |
| `@1`, `@2`... | Reference by message number |
| `@last` | Reference previous message |
| `@prev` | Alias for @last |
| `@all` | Reference all messages |
