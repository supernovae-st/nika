# TaskBox v0.11 Event Wiring Documentation

## Overview

This document details the event flow from runtime → App → ChatView → TaskBox widgets
for the v0.11 implementation. It covers all event types that need wiring and the
exact code changes required.

---

## 1. Data Structures Required

### ChatView New Fields

```rust
// In src/tui/views/chat.rs - add to ChatView struct

/// Map task_id to index in inline_content for O(1) lookup
/// Updated on TaskStarted, cleared on task terminal state
pub task_boxes: HashMap<Arc<str>, usize>,

/// Agent hierarchy: parent_task_id → Vec<child_task_id>
/// Built from AgentSpawned events, used for nested rendering
pub agent_hierarchy: HashMap<Arc<str>, Vec<Arc<str>>>,

/// Last token timestamp for velocity calculation
/// Reset on TaskStarted, updated on StreamChunk::Token
pub last_token_time: Option<Instant>,

/// Accumulated tokens since last_token_time for velocity calc
/// Formula: tokens_since_last / elapsed_ms * 1000 = tokens/sec
pub tokens_since_last_velocity: u32,
```

### InvokeBox Enhancement (Retry Badge)

```rust
// In src/tui/widgets/task_box/invoke.rs - add to InvokeBox struct

/// Current retry attempt (0 = first try, 1 = first retry, etc.)
pub retry_attempt: u32,

/// Max retry attempts configured
pub retry_max: u32,
```

## 2. ASCII Sequence Diagrams

### 2.1 TaskStarted Event Flow

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ RUNTIME → APP → CHATVIEW → TASKBOX                                                             │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘

  EventLog::emit()                   poll_runtime_events()             handle_task_started()
       │                                    │                                    │
       │   ┌─────────────────┐              │                                    │
       │   │ EventKind::     │              │                                    │
       │   │ TaskStarted {   │              │                                    │
       │   │   task_id,      │──broadcast──►│                                    │
       │   │   verb: "infer",│              │                                    │
       │   │   inputs: {...} │              │                                    │
       │   └─────────────────┘              │                                    │
       │                                    │                                    │
       │                                    │  ┌─────────────────────────────────┐
       │                                    │  │ for event in events {           │
       │                                    │  │   self.handle_chat_view_event() │
       │                                    │  │ }                               │
       │                                    │  └─────────────────────────────────┘
       │                                    │              │
       │                                    │              ▼
       │                                    │  ┌─────────────────────────────────┐
       │                                    │  │ EventKind::TaskStarted {        │
       │                                    │  │   task_id, verb, inputs         │
       │                                    │  │ } => {                          │
       │                                    │  │   self.chat_view               │
       │                                    │  │     .handle_task_started(       │
       │                                    │  │       task_id, verb, inputs     │
       │                                    │  │     );                          │
       │                                    │  │ }                               │
       │                                    │  └─────────────────────────────────┘
       │                                    │                          │
       │                                    │                          ▼
       │                                    │  ┌─────────────────────────────────────────────────┐
       │                                    │  │ ChatView::handle_task_started()                 │
       │                                    │  │ ┌─────────────────────────────────────────────┐ │
       │                                    │  │ │ 1. Match verb → create TaskBox variant      │ │
       │                                    │  │ │    "infer" → InferBox::new()                │ │

### 2.2 StreamChunk::Token → InferBox.velocity

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ STREAMING TOKEN → VELOCITY UPDATE                                                               │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘

  ChatAgent::stream()              run_unified()                handle_streaming_token()
       │                                │                                │
       │  ┌──────────────────┐          │                                │
       │  │ StreamChunk::    │          │                                │
       │  │   Token("hello") │──mpsc───►│                                │
       │  └──────────────────┘          │                                │
       │                                │                                │
       │                                │  ┌─────────────────────────────┐
       │                                │  │ while let Ok(chunk) =       │
       │                                │  │   stream_chunk_rx.try_recv()│
       │                                │  │ {                           │
       │                                │  │   match chunk {             │
       │                                │  │     Token(text) => {        │
       │                                │  │       self.chat_view        │
       │                                │  │         .handle_streaming_  │
       │                                │  │           token(&text);     │
       │                                │  │     }                       │
       │                                │  │   }                         │
       │                                │  │ }                           │
       │                                │  └─────────────────────────────┘
       │                                │              │
       │                                │              ▼
       │                                │  ┌─────────────────────────────────────────────────────┐
       │                                │  │ ChatView::handle_streaming_token(&str)              │
       │                                │  │ ┌─────────────────────────────────────────────────┐ │
       │                                │  │ │ 1. Count tokens in chunk (whitespace split)    │ │
       │                                │  │ │    let token_count = text.split_whitespace()   │ │
       │                                │  │ │                           .count() as u32;      │ │
       │                                │  │ │                                                 │ │
       │                                │  │ │ 2. Accumulate for velocity calculation         │ │
       │                                │  │ │    self.tokens_since_last_velocity += token_count│ │
       │                                │  │ │                                                 │ │
       │                                │  │ │ 3. Calculate velocity every 100ms              │ │
       │                                │  │ │    if let Some(last) = self.last_token_time {  │ │
       │                                │  │ │      let elapsed = last.elapsed();             │ │
       │                                │  │ │      if elapsed >= Duration::from_millis(100) {│ │
       │                                │  │ │        let tokens_per_sec =                    │ │
       │                                │  │ │          (self.tokens_since_last_velocity as f32)│ │
       │                                │  │ │          / elapsed.as_secs_f32();              │ │
       │                                │  │ │                                                 │ │
       │                                │  │ │        // Find running InferBox and update     │ │
       │                                │  │ │        for content in self.inline_content.iter_mut() { │
       │                                │  │ │          if let Task(TaskBox::Infer(infer)) = content { │
       │                                │  │ │            if infer.state.is_running() {       │ │
       │                                │  │ │              infer.velocity.push(tokens_per_sec);│ │
       │                                │  │ │            }                                   │ │
       │                                │  │ │          }                                     │ │
       │                                │  │ │        }                                       │ │
       │                                │  │ │                                                 │ │
       │                                │  │ │        // Reset for next window                │ │
       │                                │  │ │        self.last_token_time = Some(Instant::now());│ │
       │                                │  │ │        self.tokens_since_last_velocity = 0;   │ │
       │                                │  │ │      }                                         │ │
       │                                │  │ │    }                                           │ │
       │                                │  │ └─────────────────────────────────────────────────┘ │
       │                                │  └─────────────────────────────────────────────────────┘
       │                                │
       ▼                                ▼
```

### 2.3 AgentTurn with Metadata → Token Update

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│ AGENT TURN EVENT → TOKEN VELOCITY UPDATE                                                        │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘

  RigAgentLoop::emit()             poll_runtime_events()        handle_agent_turn_velocity()
       │                                │                                │
       │  ┌─────────────────────┐       │                                │
       │  │ EventKind::         │       │                                │
       │  │ AgentTurn {         │       │                                │
       │  │   task_id,          │       │                                │
       │  │   turn_index: 2,    │──────►│                                │
       │  │   kind: "continue", │       │                                │
       │  │   metadata: Some(   │       │                                │
       │  │     AgentTurnMeta { │       │                                │
       │  │       input_tokens, │       │                                │
       │  │       output_tokens,│       │                                │
       │  │       ...           │       │                                │
       │  │     }               │       │                                │
       │  │   )                 │       │                                │
       │  │ }                   │       │                                │
       │  └─────────────────────┘       │                                │
       │                                │                                │
       │                                │  ┌────────────────────────────────────────────────┐
       │                                │  │ EventKind::AgentTurn {                        │
       │                                │  │   task_id, turn_index, kind, metadata         │
       │                                │  │ } => {                                        │
       │                                │  │   self.chat_view.on_agent_turn(turn_index);   │
       │                                │  │   if let Some(meta) = metadata {              │
       │                                │  │     self.chat_view                            │
       │                                │  │       .handle_agent_turn_velocity(            │
       │                                │  │         &task_id, &meta                       │
       │                                │  │       );                                      │
       │                                │  │   }                                           │
       │                                │  │ }                                             │
       │                                │  └────────────────────────────────────────────────┘
       │                                │                       │
       │                                │                       ▼
       │                                │  ┌────────────────────────────────────────────────────┐
       │                                │  │ ChatView::handle_agent_turn_velocity(              │
       │                                │  │   task_id: &Arc<str>,                              │
       │                                │  │   metadata: &AgentTurnMetadata                     │
       │                                │  │ ) {                                                │
       │                                │  │   // Find AgentBox by task_id                      │
       │                                │  │   if let Some(&idx) = self.task_boxes.get(task_id) { │
       │                                │  │     if let Some(InlineContent::Task(              │
       │                                │  │       TaskBox::Agent(agent)                       │
       │                                │  │     )) = self.inline_content.get_mut(idx) {       │
       │                                │  │                                                    │
       │                                │  │       // Calculate tokens/sec for this turn       │
       │                                │  │       // Approximate: assume turn took ~2-5 sec   │
       │                                │  │       let output_tokens = metadata.output_tokens; │
       │                                │  │       let tokens_per_sec = output_tokens as f32   │
       │                                │  │                            / 3.0; // estimate     │
       │                                │  │                                                    │
       │                                │  │       agent.velocity.push(tokens_per_sec);        │
       │                                │  │       agent.current_turn = agent.current_turn     │
       │                                │  │                            .saturating_add(1);    │
       │                                │  │     }                                              │
       │                                │  │   }                                                │
       │                                │  │ }                                                  │
       │                                │  └────────────────────────────────────────────────────┘
       │                                │
       ▼                                ▼
```

       │                                │  │ ) {                                                 │
       │                                │  │   // Find InvokeBox by task_id                      │

       │                                │  │     }                                               │

### 2.6 TaskCompleted/TaskFailed → BoxState Update

```

/// Handle events for ChatView activity stack
///
/// Updates the ChatView's inline content and activity items when
/// MCP, Provider, or Agent events occur.
/// v0.11: Added TaskStarted/Completed/Failed handling for TaskBox wiring
fn handle_chat_view_event(&mut self, kind: &EventKind) {
    match kind {
        // ═══════════════════════════════════════════
        // TASK LIFECYCLE EVENTS (v0.11 NEW)
        // ═══════════════════════════════════════════
        EventKind::TaskStarted { task_id, verb, inputs } => {

        }
        EventKind::TaskFailed { task_id, error, duration_ms } => {
            self.chat_view.handle_task_failed(task_id, error, *duration_ms);
        }

        // ═══════════════════════════════════════════
        // AGENT EVENTS (v0.8.1 phase tracking + v0.11 hierarchy)
        // ═══════════════════════════════════════════
        EventKind::AgentStart { task_id, .. } => {
            self.chat_view.on_agent_start();
        }
        EventKind::AgentTurn { task_id, turn_index, kind, metadata } => {
            if kind == "started" {
                self.chat_view.on_agent_start();
            } else {
                self.chat_view.on_agent_turn(*turn_index);
            }
            // v0.11: Update velocity from metadata
            if let Some(meta) = metadata {
                self.chat_view.handle_agent_turn_velocity(task_id, meta);
            }
        }
        EventKind::AgentComplete { task_id, turns, .. } => {
            self.chat_view.on_agent_complete();
        }
        EventKind::AgentSpawned { parent_task_id, child_task_id, depth } => {
            self.chat_view.handle_agent_spawned(
                parent_task_id,
                child_task_id,
                *depth,
            );
        }

        // ═══════════════════════════════════════════
        // MCP EVENTS (existing + v0.11 retry)
        // ═══════════════════════════════════════════
        EventKind::McpInvoke { mcp_server, tool, params, .. } => {
            let tool_name = tool.as_deref().unwrap_or("resource");
            let params_str = params
                .as_ref()
                .map(|p| serde_json::to_string(p).unwrap_or_default())
                .unwrap_or_default();
            self.chat_view.add_mcp_call(tool_name, mcp_server, &params_str);
            self.chat_view.on_mcp_invoke(tool_name, mcp_server);
        }
        EventKind::McpResponse { is_error, response, .. } => {
            if *is_error {
                let error_msg = response
                    .as_ref()
                    .and_then(|r| r.get("error"))
                    .and_then(|e| e.as_str())
                    .unwrap_or("MCP call failed");
                self.chat_view.fail_mcp_call(error_msg);
            } else {
                let result_str = response
                    .as_ref()
                    .map(|r| serde_json::to_string(r).unwrap_or_default())
                    .unwrap_or_default();
                self.chat_view.complete_mcp_call(&result_str);
            }
            self.chat_view.on_mcp_response();
        }
        // v0.11: MCP retry handling
        EventKind::McpRetry { task_id, attempt, max_attempts, .. } => {
            self.chat_view.handle_mcp_retry(task_id, *attempt, *max_attempts);
        }

        // ═══════════════════════════════════════════
        // PROVIDER EVENTS (existing)
        // ═══════════════════════════════════════════
        EventKind::ProviderCalled { model, prompt_len, .. } => {

            self.chat_view.update_tokens(

                self.chat_view.session_context.total_cost + cost_usd,
            );

        // ═══════════════════════════════════════════
        // MCP CONNECTION EVENTS (existing)
        // ═══════════════════════════════════════════
        EventKind::McpConnected { server_name } => {
            self.chat_view.mark_mcp_server_connected(server_name);
            self.state.dirty.status = true;
        }
        EventKind::McpError { server_name, .. } => {
            self.chat_view.mark_mcp_server_error(server_name);
            self.state.dirty.status = true;
        }

        _ => {}
    }
}

/// Handle TaskStarted event - create appropriate TaskBox variant
pub fn handle_task_started(
    &mut self,
    task_id: Arc<str>,
    verb: &str,
    inputs: serde_json::Value,
) {
    use crate::tui::widgets::task_box::*;

    // Create verb-specific TaskBox
    let task_box = match verb {
        "infer" => {
            let model = inputs.get("model")
                .and_then(|v| v.as_str())
                .unwrap_or("unknown");
            let prompt = inputs.get("prompt")
                .and_then(|v| v.as_str())
                .unwrap_or("")
                .chars()
                .take(100)
                .collect::<String>();
            TaskBox::Infer(
                InferBox::new(model, prompt)
                    .with_state(BoxState::running())
            )
        }
        "exec" => {
            let command = inputs.get("command")
                .and_then(|v| v.as_str())
                .unwrap_or("(command)");
            TaskBox::Exec(
                ExecBox::new(command)
                    .with_state(BoxState::running())
            )
        }
        "fetch" => {
            let method = inputs.get("method")
                .and_then(|v| v.as_str())
                .unwrap_or("GET");
            let url = inputs.get("url")
                .and_then(|v| v.as_str())
                .unwrap_or("(url)");
            TaskBox::Fetch(
                FetchBox::new(method, url)
                    .with_state(BoxState::running())
            )
        }
        "invoke" => {
            let tool = inputs.get("tool")
                .and_then(|v| v.as_str())
                .unwrap_or("(tool)");
            let server = inputs.get("server")
                .and_then(|v| v.as_str())
                .unwrap_or("(server)");
            let params = inputs.get("params")
                .cloned()
                .unwrap_or(serde_json::Value::Null);
            TaskBox::Invoke(
                InvokeBox::new(tool, server)
                    .with_params(params)
                    .with_state(BoxState::running())
            )
        }
        "agent" => {
            let prompt = inputs.get("prompt")
                .and_then(|v| v.as_str())
                .unwrap_or("(agent goal)")
                .to_string();
            TaskBox::Agent(
                AgentBox::new(task_id.to_string(), prompt)
                    .with_state(BoxState::running())
            )
        }
        _ => {
            tracing::warn!(verb = %verb, "Unknown verb for TaskBox");
            return;
        }
    };

    // Track in task_boxes map for O(1) lookup
    let idx = self.inline_content.len();
    self.task_boxes.insert(Arc::clone(&task_id), idx);
    self.inline_content.push(InlineContent::Task(task_box));

    // Reset velocity tracking
    self.last_token_time = Some(Instant::now());
    self.tokens_since_last_velocity = 0;

    // Add to activity stack
    self.activity_items.push(ActivityItem::hot(
        format!("{}-{}", verb, task_id),
        verb,
    ));

    self.auto_scroll_to_bottom();
}

/// Handle TaskCompleted event - update BoxState to success
pub fn handle_task_completed(&mut self, task_id: &Arc<str>, duration_ms: u64) {
    if let Some(&idx) = self.task_boxes.get(task_id) {
        if let Some(InlineContent::Task(task_box)) = self.inline_content.get_mut(idx) {
            *task_box.state_mut() = BoxState::success(duration_ms);
        }
        self.task_boxes.remove(task_id);
    }
    self.transition_activity_to_warm(&task_id.to_string());
}

/// Handle TaskFailed event - update BoxState to failed
pub fn handle_task_failed(&mut self, task_id: &Arc<str>, error: &str, duration_ms: u64) {
    if let Some(&idx) = self.task_boxes.get(task_id) {
        if let Some(InlineContent::Task(task_box)) = self.inline_content.get_mut(idx) {
            *task_box.state_mut() = BoxState::failed(error, duration_ms);
        }
        self.task_boxes.remove(task_id);
    }
    self.auto_scroll_to_bottom();
}

/// Handle streaming token - update velocity for InferBox
pub fn handle_streaming_token(&mut self, token_text: &str) {
    use std::time::Duration;

    // Count "tokens" (approximation: whitespace-split words)
    let token_count = token_text.split_whitespace().count().max(1) as u32;
    self.tokens_since_last_velocity += token_count;

    // Calculate velocity every 100ms
    if let Some(last_time) = self.last_token_time {
        let elapsed = last_time.elapsed();
        if elapsed >= Duration::from_millis(100) {
            let tokens_per_sec = (self.tokens_since_last_velocity as f32)
                / elapsed.as_secs_f32();

            // Find running InferBox and push velocity sample
            for content in self.inline_content.iter_mut().rev() {
                if let InlineContent::Task(TaskBox::Infer(infer)) = content {
                    if infer.state.is_running() {
                        infer.velocity.push(tokens_per_sec);
                        break;
                    }
                }
            }

            // Reset window
            self.last_token_time = Some(Instant::now());
            self.tokens_since_last_velocity = 0;
        }
    }
}

/// Handle AgentTurn with metadata - update velocity for AgentBox
pub fn handle_agent_turn_velocity(
    &mut self,
    task_id: &Arc<str>,
    metadata: &crate::event::AgentTurnMetadata,
) {
    // Find AgentBox by task_id
    if let Some(&idx) = self.task_boxes.get(task_id) {
        if let Some(InlineContent::Task(TaskBox::Agent(agent))) =
            self.inline_content.get_mut(idx)
        {
            // Estimate tokens/sec (assume turn took ~3 seconds average)
            let tokens_per_sec = metadata.output_tokens as f32 / 3.0;
            agent.velocity.push(tokens_per_sec);
            agent.current_turn = agent.current_turn.saturating_add(1);
        }
    }
}

/// Handle MCP retry event - update InvokeBox retry badge
pub fn handle_mcp_retry(&mut self, task_id: &Arc<str>, attempt: u32, max_attempts: u32) {
    // Try by task_id first
    if let Some(&idx) = self.task_boxes.get(task_id) {
        if let Some(InlineContent::Task(TaskBox::Invoke(invoke))) =
            self.inline_content.get_mut(idx)
        {
            invoke.retry_attempt = attempt;
            invoke.retry_max = max_attempts;
            return;
        }
    }

    // Fallback: find last running InvokeBox
    for content in self.inline_content.iter_mut().rev() {
        if let InlineContent::Task(TaskBox::Invoke(invoke)) = content {
            if invoke.state.is_running() {
                invoke.retry_attempt = attempt;
                invoke.retry_max = max_attempts;
                break;
            }
        }
    }
}

/// Handle AgentSpawned event - update hierarchy
pub fn handle_agent_spawned(
    &mut self,
    parent_id: &Arc<str>,
    child_id: &Arc<str>,
    depth: u32,
) {
    use crate::tui::widgets::task_box::*;

    // Add to hierarchy map
    self.agent_hierarchy
        .entry(Arc::clone(parent_id))
        .or_default()
        .push(Arc::clone(child_id));

    // Update parent AgentBox with child reference
    if let Some(&idx) = self.task_boxes.get(parent_id) {
        if let Some(InlineContent::Task(TaskBox::Agent(parent_agent))) =
            self.inline_content.get_mut(idx)
        {
            // Create placeholder child box
            let child_box = AgentBox::new(
                child_id.to_string(),
                format!("(spawned at depth {})", depth),
            ).with_state(BoxState::running());

            parent_agent.children.push(TaskBox::Agent(child_box));
        }
    }
}
