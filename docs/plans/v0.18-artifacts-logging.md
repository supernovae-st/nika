# Nika v0.18 — Artifacts & Logging System

## Overview

This document details the implementation plan for the **Nika Artifacts System** — a comprehensive file output and logging mechanism for workflow automation.

**Version**: Nika v0.18.0 / workflow schema `nika/workflow@0.10`
**Status**: Design complete, ready for implementation
**Author**: Claude + Thibaut
**Date**: 2026-03-03

---

## 1. Problem Statement

### Current Limitations

1. **No declarative file output**: Tasks can only write files using `nika_write` builtin or `exec` with `shell: true`
2. **No workflow-level output configuration**: Each task must manage its own file I/O
3. **No automatic artifact tracking**: No visibility into what files were created during execution
4. **Limited logging control**: All output goes to the same stream without filtering
5. **`output:` conflates two concerns**: Parsing/validation vs. persistence

### Design Goals

1. **Declarative file persistence**: Specify output paths in YAML, not code
2. **Atomic writes**: Prevent partial files on failure (temp + rename pattern)
3. **Workflow-level defaults**: Configure once, apply to many tasks
4. **Event integration**: Track artifacts in EventLog for TUI/replay
5. **Logging levels**: Filter what appears in console vs. log files
6. **Zero migration burden**: Existing workflows unchanged (backward compatible)

### 2.1 Industry Best Practices (Perplexity Research)

| Practice | Source | Application to Nika |
|----------|--------|---------------------|
| **Immutable artifacts** | CI/CD (GitHub Actions, GitLab) | Use unique naming with `{{run_id}}` |

### 2.2 Tokio Async File I/O (Context7)

```rust
use tokio::fs::File;
use tokio::io::{AsyncWriteExt, BufWriter};

// Recommended pattern: BufWriter + flush + sync
let file = File::create("output.txt").await?;
let mut writer = BufWriter::new(file);
writer.write_all(content.as_bytes()).await?;
writer.flush().await?;
```

**Atomic write pattern** (from existing `tools/write.rs`):
```rust
// 1. Write to temp file
let tmp = tempfile::NamedTempFile::new_in(parent_dir)?;
// 2. Write content with sync
file.write_all(content.as_bytes())?;
file.sync_all()?;
// 3. Atomic rename
tmp.persist(path)?;
```

```rust
//! Artifact configuration for file output (v0.10)

use serde::Deserialize;

/// Workflow-level artifact defaults
#[derive(Debug, Clone, Deserialize, Default)]
pub struct ArtifactsConfig {
    /// Base directory for artifacts (supports templates)
    #[serde(default)]
    pub dir: Option<String>,

    /// Default output format
    #[serde(default)]
    pub format: ArtifactFormat,

    /// Default write mode
    #[serde(default)]
    pub mode: ArtifactMode,

    /// Generate artifacts.json manifest
    #[serde(default)]
    pub manifest: bool,
}

/// Task-level artifact specification
#[derive(Debug, Clone, Deserialize)]
#[serde(untagged)]
pub enum ArtifactSpec {
    /// Simple boolean: use defaults
    Enabled(bool),

    /// Single artifact with options
    Single(ArtifactOutput),

    /// Multiple artifacts
    Multiple(Vec<ArtifactOutput>),
}

/// Individual artifact output configuration
#[derive(Debug, Clone, Deserialize)]
pub struct ArtifactOutput {
    /// Output path (supports templates)
    pub path: String,

    /// Which binding to save (default: task result)
    #[serde(default)]
    pub source: Option<String>,

    /// Output format override
    #[serde(default)]
    pub format: Option<ArtifactFormat>,

    /// Write mode override
    #[serde(default)]
    pub mode: Option<ArtifactMode>,
}

/// Artifact output format
#[derive(Debug, Clone, Copy, Deserialize, Default, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum ArtifactFormat {
    #[default]
    Text,
    Json,
    Yaml,
}

/// File write mode
#[derive(Debug, Clone, Copy, Deserialize, Default, PartialEq)]
#[serde(rename_all = "lowercase")]
pub enum ArtifactMode {
    /// Overwrite existing file (default)
    #[default]
    Overwrite,

    /// Append to existing file
    Append,

    /// Create unique filename if exists (e.g., file-1.json)
    Unique,

    /// Fail if file already exists
    Fail,
}
```

## 6. Runtime Implementation

### 6.1 ArtifactWriter Module

```rust
// New file: runtime/artifact.rs

use tokio::fs::{self, File, OpenOptions};
use tokio::io::{AsyncWriteExt, BufWriter};
use tempfile::NamedTempFile;

pub struct ArtifactWriter {
    config: ArtifactsConfig,
    run_id: String,
    workflow_name: String,
    manifest: Vec<ArtifactEntry>,
}

impl ArtifactWriter {
    /// Write artifact with atomic semantics
    pub async fn write(
        &mut self,
        spec: &ArtifactOutput,
        content: &str,
        task_id: &str,
    ) -> Result<ArtifactEntry> {
        let path = self.resolve_path(&spec.path, task_id)?;
        let format = spec.format.unwrap_or(self.config.format);
        let mode = spec.mode.unwrap_or(self.config.mode);

        // Ensure parent directory exists
        if let Some(parent) = path.parent() {
            fs::create_dir_all(parent).await?;
        }

        // Format content
        let formatted = self.format_content(content, format)?;

        // Write based on mode
        let final_path = match mode {
            ArtifactMode::Overwrite => self.write_atomic(&path, &formatted).await?,
            ArtifactMode::Append => self.write_append(&path, &formatted).await?,
            ArtifactMode::Unique => self.write_unique(&path, &formatted).await?,
            ArtifactMode::Fail => self.write_fail(&path, &formatted).await?,
        };

        // Calculate checksum
        let checksum = xxhash_rust::xxh3::xxh3_64(formatted.as_bytes());

        let entry = ArtifactEntry {
            task_id: task_id.to_string(),
            path: final_path.display().to_string(),
            size: formatted.len() as u64,
            format: format.to_string(),
            checksum: format!("{:016x}", checksum),
            created_at: chrono::Utc::now(),
        };

        self.manifest.push(entry.clone());
        Ok(entry)
    }

    /// Atomic write: temp file → sync → rename
    async fn write_atomic(&self, path: &Path, content: &str) -> Result<PathBuf> {
        let parent = path.parent().unwrap_or(Path::new("."));

        // Create temp file in same directory (for atomic rename)
        let tmp = tempfile::Builder::new()
            .prefix(".nika-artifact-")
            .tempfile_in(parent)?;

        // Write with sync
        let file = tmp.as_file();
        use std::io::Write;
        file.write_all(content.as_bytes())?;
        file.sync_all()?;

        // Atomic rename
        tmp.persist(path)?;

        Ok(path.to_path_buf())
    }

    /// Generate manifest file
    pub async fn write_manifest(&self, dir: &Path) -> Result<PathBuf> {
        let manifest_path = dir.join("artifacts.json");
        let manifest = serde_json::to_string_pretty(&self.manifest)?;
        self.write_atomic(&manifest_path, &manifest).await
    }
}
```

### 6.2 Integration in Runner

```rust
// In runtime/runner.rs

impl WorkflowRunner {
    async fn run_task(&mut self, task: &Task) -> Result<TaskResult> {
        // ... existing execution logic ...

        let result = self.execute_task_action(task).await?;

        // NEW: Write artifact if configured (v0.10)
        if let Some(artifact_spec) = &task.artifact {
            self.write_task_artifact(task, &result, artifact_spec).await?;
        }

        Ok(result)
    }

    async fn write_task_artifact(
        &mut self,
        task: &Task,
        result: &TaskResult,
        spec: &ArtifactSpec,
    ) -> Result<()> {
        let artifacts = match spec {
            ArtifactSpec::Enabled(false) => return Ok(()),
            ArtifactSpec::Enabled(true) => {
                // Use defaults: {dir}/{task_id}.{format}
                vec![ArtifactOutput {
                    path: format!("{}.{}", task.id, self.artifact_config.format),
                    source: None,
                    format: None,
                    mode: None,
                }]
            }
            ArtifactSpec::Single(output) => vec![output.clone()],
            ArtifactSpec::Multiple(outputs) => outputs.clone(),
        };

        for output in artifacts {
            let content = match &output.source {
                Some(binding) => self.datastore.get(binding)?,
                None => result.output.clone(),
            };

            let entry = self.artifact_writer.write(&output, &content, &task.id).await?;

            // Emit event
            self.event_log.emit(EventKind::ArtifactWritten {
                task_id: task.id.clone().into(),
                path: entry.path.clone(),
                size: entry.size,
                format: entry.format.clone(),
                mode: output.mode.unwrap_or_default().to_string(),
                checksum: entry.checksum.clone(),
            });
        }

        Ok(())
    }
}
```
