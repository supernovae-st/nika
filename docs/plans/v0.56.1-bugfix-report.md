> Windows + aarch64-gnu cross-compile are broken. Doc tests + CI config need fixes.

## P0 — Build Failures (2 issues)

### BUG-1: Windows build fails — `nika_daemon` is unix-only

**Severity**: P0 (Windows binary not published)
**CI job**: `Build x86_64-pc-windows-msvc`
**Error**: `E0433: failed to resolve: use of unresolved module or unlinked crate nika_daemon`

**Root cause**: `nika-engine/src/secrets/fallback.rs` uses `nika_daemon::daemon_dir()` without a `#[cfg(unix)]` gate. The `nika-daemon` dep is `cfg(unix)` only in `nika-engine/Cargo.toml`, so on Windows the crate doesn't exist.

**Affected lines**:
```
nika-engine/src/secrets/fallback.rs:94  — nika_daemon::daemon_dir()
nika-engine/src/secrets/fallback.rs:135 — nika_daemon::daemon_dir()
nika-engine/src/secrets/fallback.rs:175 — nika_daemon::daemon_dir()
```

**Fix**: Wrap the 3 `nika_daemon::daemon_dir()` calls in `#[cfg(unix)]` blocks. On non-unix, fall back to `dirs::home_dir().unwrap_or_default().join(".nika")` directly (skip the daemon dir resolution).

```rust
// Before:
let nika_home = nika_daemon::daemon_dir()
    .parent()
    .map(|p| p.to_path_buf())
    .unwrap_or_else(|| dirs::home_dir().unwrap().join(".nika"));

// After:
#[cfg(unix)]
let nika_home = nika_daemon::daemon_dir()
    .parent()
    .map(|p| p.to_path_buf())
    .unwrap_or_else(|| dirs::home_dir().unwrap_or_default().join(".nika"));
#[cfg(not(unix))]
let nika_home = dirs::home_dir().unwrap_or_default().join(".nika");
```

### BUG-2: aarch64-linux-gnu cross-compile references removed feature

**Severity**: P0 (aarch64 gnu binary not published)
**CI job**: `Build aarch64-unknown-linux-gnu`
**Error**: `[cross] error: Errors encountered before cross compilation, aborting`

**Root cause**: `.github/workflows/release.yml:198` uses `--features tui,nika-daemon,media-core,lsp` but the `nika-daemon` feature was removed from the nika binary when we removed `native-keychain`. The feature `nika-daemon` never existed — it was a typo/confusion with `native-keychain` which forwarded to nika-engine.

**Fix**: Update `.github/workflows/release.yml` line 198:
```yaml
# Before:
run: cross build --release --target ${{ matrix.target }} --no-default-features --features tui,nika-daemon,media-core,lsp

# After:
run: cross build --release --target ${{ matrix.target }} --no-default-features --features tui,serve,media-core,lsp
```

Also update the step name on line 195 from "minus keychain" to just "cross" since keychain is gone.

### BUG-4: Validate Nika Workflows CI uses shell glob that doesn't expand

**Severity**: P1 (CI always fails)
**CI job**: `Validate Nika Workflows`
**Error**: `[NIKA-003] Workflow file not found: examples/*.nika.yaml`

**Root cause**: The CI step runs `nika validate 'examples/*.nika.yaml'` with quotes around the glob, so the shell doesn't expand it and nika receives the literal `*`.

**Fix**: Either remove the quotes to let shell expand, or use `find` + `xargs`:
```yaml
# Option A: unquoted glob
run: nika validate examples/*.nika.yaml

# Option B: explicit find
run: find examples -name '*.nika.yaml' -exec nika validate {} +
```
