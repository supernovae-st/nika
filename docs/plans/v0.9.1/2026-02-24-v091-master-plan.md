# Nika v0.9.1 — Chat-as-DAG Master Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Unify Chat TUI with Workflow DAG system so every chat message becomes a traceable Task node.

**Architecture:** Chat messages become StableGraph nodes with @mention edges. Builtin `nika:*` tools enable HITL and workflow composition. Same Executor runs both Chat and Workflow DAGs.

**Tech Stack:** petgraph (StableGraph), rig-core (ToolDyn), humantime, evalexpr, parking_lot, ratatui
