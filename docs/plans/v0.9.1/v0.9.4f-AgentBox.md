# v0.9.4f: AgentBox — Multi-Turn Agent Widget

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

> **NO v1.0** — Nika stays in 0.XX versioning. No planning toward v1.0. After v0.9.5, continue to v0.10.0.

**Goal:** Comprehensive AgentBox widget for visualizing multi-turn agentic loops with nested children, token tracking, and turn progression.

**Architecture:** AgentBox represents the `agent:` verb, the most complex TaskBox. It contains nested child TaskBoxes (InvokeBox, InferBox, etc.), tracks turns, tokens, cost, and displays the final response. Supports recursive spawn_agent visualization.

**Tech Stack:** Rust, ratatui, serde_json, TaskBoxBehavior trait from Foundation, recursive child rendering

**Prerequisites:** v0.9.4a-TaskBoxFoundation.md + all other TaskBox specs must be complete

### Nested TaskBox Enum

```rust
/// Unified TaskBox enum for polymorphic children
#[derive(Debug, Clone)]
pub enum TaskBox {
    Infer(InferBox),
    Exec(ExecBox),
    Fetch(FetchBox),
    Invoke(InvokeBox),
    Agent(Box<AgentBox>), // Box to prevent infinite size
}

impl TaskBox {
    /// Get required height for any variant
    pub fn required_height(&self) -> u16 {
        match self {
            Self::Infer(b) => b.required_height(),
            Self::Exec(b) => b.required_height(),
            Self::Fetch(b) => b.required_height(),
            Self::Invoke(b) => b.required_height(),
            Self::Agent(b) => b.required_height(),
        }
    }

    /// Get state for any variant
    pub fn state(&self) -> &BoxState {
        match self {
            Self::Infer(b) => &b.state,
            Self::Exec(b) => &b.state,
            Self::Fetch(b) => &b.state,
            Self::Invoke(b) => &b.state,
            Self::Agent(b) => &b.state,
        }
    }

    /// Render any variant
    pub fn render(&self, area: Rect, buf: &mut Buffer) {
        match self {
            Self::Infer(b) => b.clone().render(area, buf),
            Self::Exec(b) => b.clone().render(area, buf),
            Self::Fetch(b) => b.clone().render(area, buf),
            Self::Invoke(b) => b.clone().render(area, buf),
            Self::Agent(b) => b.as_ref().clone().render(area, buf),
        }
    }
}
```

## Performance Requirements

**From v0.9.4a-TaskBoxFoundation:**

### Mandatory Patterns

| Pattern | Implementation | Budget |
|---------|----------------|--------|
| Widget for &AgentBox | `impl Widget for &AgentBox` | 0 clones/render |
| Widget for &TaskBox | Children render without clone | Critical for nested |
| StyleCache | Use `STYLE_CACHE.agent_border` | <10ns lookup |
| FormatBuf | Format turn/tokens/cost | 0 heap allocs |
| AnimationState | Share animation frame with children | <1µs/tick |

### Children Rendering (Critical)

The existing implementation has a clone issue that must be fixed:

```rust

    child.clone().render(child_area, buf);  // ❌ BAD
}

// AFTER (zero-copy render)
for child in &self.children {
    child.render(child_area, buf);  // ✅ GOOD
}

// Requires: impl Widget for &TaskBox

    fn render(self, area: Rect, buf: &mut Buffer) {
        match self {

            TaskBox::Fetch(b) => b.render(area, buf),
            TaskBox::Invoke(b) => b.render(area, buf),
            TaskBox::Agent(b) => b.render(area, buf),
```

### CancellationToken Integration (Critical for Streaming)

Agent execution MUST support graceful cancellation via `tokio_util::sync::CancellationToken`:

```rust
use tokio_util::sync::CancellationToken;

/// AgentBox with cancellation support
impl AgentBox {
    /// Cancel token - shared between UI and executor
    pub cancellation_token: Option<CancellationToken>,
}

/// In RigAgentLoop
impl RigAgentLoop {
    pub async fn run_with_cancellation(
        &mut self,
        cancel_token: CancellationToken,
    ) -> Result<AgentResult, NikaError> {
        loop {
            tokio::select! {
                // Check cancellation first (biased)
                biased;
                _ = cancel_token.cancelled() => {
                    return Err(NikaError::Cancelled {
                        task_id: self.task_id.clone(),
                        turn: self.current_turn,
                    });
                }
                // Run next turn
                result = self.run_turn() => {
                    match result {
                        Ok(TurnResult::Continue) => continue,
                        Ok(TurnResult::Complete(response)) => {
                            return Ok(AgentResult::complete(response));
                        }
                        Err(e) => return Err(e),
                    }
                }
            }
        }
    }
}

/// ChatView cancellation handling
impl ChatView {
    pub fn cancel_active_agent(&mut self) {
        if let Some(TaskBox::Agent(ref mut box_)) = self.active_boxes.last_mut() {
            if let Some(token) = &box_.cancellation_token {
                token.cancel();
                box_.state.fail("Cancelled by user");
            }
        }
    }
}
```

**Key Rules:**
1. **Always use `biased;` in select!** — Cancellation must be checked first
2. **Propagate to children** — When parent is cancelled, all child agents must also cancel
3. **Emit event** — `EventKind::AgentCancelled { task_id, turn }` for observability
4. **Cleanup** — Drop any MCP connections held by the cancelled agent

**Error Code:**
```rust
#[error("[NIKA-115] Agent '{task_id}' cancelled at turn {turn}")]
Cancelled { task_id: String, turn: u32 },
```

```rust
impl AgentBox {
    /// Calculate turn progress (0.0 to 1.0)
    pub fn turn_progress(&self) -> f64 {
        if self.max_turns == 0 {
            return 0.0;
        }
        self.turn as f64 / self.max_turns as f64
    }

    /// Format turn progress bar for display
    pub fn format_turn_bar(&self, width: usize) -> String {
        let progress = self.turn_progress();
        let filled = (progress * (width - 10) as f64) as usize;
        let empty = (width - 10).saturating_sub(filled);
        let percent = (progress * 100.0) as u32;

        format!(
            "{}{} {}% (turn {} of {})",
            "█".repeat(filled),
            "░".repeat(empty),
            percent,
            self.turn,
            self.max_turns
        )
    }

    /// Calculate average turn duration
    pub fn avg_turn_duration_ms(&self) -> Option<u64> {
        if self.turn_durations.is_empty() {
            return None;
        }
        let sum: u64 = self.turn_durations.iter().sum();
        Some(sum / self.turn_durations.len() as u64)
    }

    /// Record turn completion
    pub fn complete_turn(&mut self, duration_ms: u64) {
        self.turn_durations.push(duration_ms);
        self.turn += 1;
    }
}
```

```rust
impl AgentBox {
    /// Select next child (wrap around)
    pub fn select_next_child(&mut self) {
        if self.children.is_empty() {
            return;
        }
        self.selected_child = Some(match self.selected_child {
            None => 0,
            Some(i) => (i + 1) % self.children.len(),
        });
    }

    /// Select previous child (wrap around)
    pub fn select_prev_child(&mut self) {
        if self.children.is_empty() {
            return;
        }
        self.selected_child = Some(match self.selected_child {
            None => self.children.len() - 1,
            Some(0) => self.children.len() - 1,
            Some(i) => i - 1,
        });
    }

    /// Update scroll to keep selection visible
    pub fn update_scroll_for_selection(&mut self, visible_count: u16) {
        if let Some(selected) = self.selected_child {
            let selected = selected as u16;
            let scroll = self.children_scroll;

            // Scroll down if selection below visible area
            if selected >= scroll + visible_count {
                self.children_scroll = selected - visible_count + 1;
            }
            // Scroll up if selection above visible area
            else if selected < scroll {
                self.children_scroll = selected;
            }
        }
    }

    /// Get reference to selected child
    pub fn get_selected_child(&self) -> Option<&TaskBox> {
        self.selected_child.and_then(|i| self.children.get(i))
    }

    /// Get mutable reference to selected child
    pub fn get_selected_child_mut(&mut self) -> Option<&mut TaskBox> {
        self.selected_child.and_then(|i| self.children.get_mut(i))
    }

    /// Clear selection
    pub fn clear_selection(&mut self) {
        self.selected_child = None;
    }
}
```

```rust
impl AgentBox {
    /// Calculate estimated cost in USD
    pub fn calculate_cost(&self) -> f64 {
        let (input_rate, output_rate) = self.get_pricing();

        let input_cost = self.tokens_in as f64 * input_rate / 1_000_000.0;
        let output_tokens = self.tokens_out + self.thinking_tokens.unwrap_or(0);
        let output_cost = output_tokens as f64 * output_rate / 1_000_000.0;

        input_cost + output_cost
    }

    /// Get pricing rates ($/million tokens) based on provider/model
    fn get_pricing(&self) -> (f64, f64) {
        let model = self.model.as_deref().unwrap_or("");
        let provider = self.provider.as_deref().unwrap_or("");

        match (provider, model) {
            // Claude pricing (as of 2025)
            ("claude", m) if m.contains("opus") => (15.0, 75.0),
            ("claude", m) if m.contains("sonnet") => (3.0, 15.0),
            ("claude", m) if m.contains("haiku") => (0.25, 1.25),

            // OpenAI pricing
            ("openai", "gpt-4o") => (5.0, 15.0),
            ("openai", "gpt-4o-mini") => (0.15, 0.6),
            ("openai", m) if m.contains("gpt-4") => (10.0, 30.0),

            // Mistral pricing
            ("mistral", m) if m.contains("large") => (3.0, 9.0),
            ("mistral", _) => (1.0, 3.0),

            // Groq (free tier, estimate)
            ("groq", _) => (0.05, 0.1),

            // DeepSeek pricing
            ("deepseek", _) => (0.14, 0.28),

            // Default fallback
            _ => (3.0, 15.0),
        }
    }

    /// Update cost from calculated value
    pub fn update_cost(&mut self) {
```

```rust
                .take(5) // Max 5 visible in compact

                .sum::<u16>()

        let response_extra = if self.expanded_response && self.final_response.is_some() {
            self.final_response.as_ref()
                .map(|r| r.lines().count().min(15))
                .unwrap_or(0) as u16
        } else if self.final_response.is_some() {
            3 // Truncated preview
        } else {
            0
        };

        base + thinking_extra + children_extra + response_extra
    }

        let mut actions = vec![TaskBoxAction::ToggleExpand];

        if !self.children.is_empty() {
            actions.push(TaskBoxAction::ToggleChildren);
        }

        if self.thinking.is_some() {
            actions.push(TaskBoxAction::ToggleThinking);
        }

        if self.final_response.is_some() {

        }

                true
            }

                true
            }
```

```rust
        let metric_style = Style::default().fg(Color::Rgb(148, 163, 184));
        let thinking_style = Style::default().fg(Color::Rgb(168, 162, 158)); // Warm gray
        let error_style = Style::default().fg(Color::Rgb(239, 68, 68));

        let inner_width = (area.width - 2) as usize;
        let status_icon = self.state.icon();
        let status_suffix = self.state.suffix();

        // === TOP BORDER ===
        let icon = self.effective_icon();
        let label = self.effective_label();
        let prompt_truncated = Self::truncate(&self.prompt, inner_width.saturating_sub(35));
        let title = format!(
            "╭─ {} {}: {} {} {} ─╮",
            icon, label, prompt_truncated, status_icon, status_suffix
        );
        buf.set_string(area.x, area.y, &title, border_style);

        let mut y = area.y + 1;

        // === METRICS BAR ===
        if y < area.y + area.height - 1 {
            buf.set_string(area.x, y, "│", border_style);
            buf.set_string(area.x + area.width - 1, y, "│", border_style);

            let metrics = format!(
                "Turn {}/{} │ 📊 {} in / {} out │ 💰 ${:.2} │ 🔌 {} tools",
                self.turn, self.max_turns,
                Self::format_tokens(self.tokens_in),
                Self::format_tokens(self.tokens_out),
                self.cost,
                self.tool_calls
            );
            buf.set_string(area.x + 2, y, Self::truncate(&metrics, inner_width - 2), metric_style);
            y += 1;
        }

        // === TURN PROGRESS BAR (Expanded mode, running state) ===
        if matches!(self.render_mode, RenderMode::Expanded | RenderMode::Full)
            && self.state.is_running()
            && y < area.y + area.height - 1
        {
            buf.set_string(area.x, y, "│", border_style);
            buf.set_string(area.x + area.width - 1, y, "│", border_style);
            buf.set_string(area.x + 2, y, &self.format_turn_bar(inner_width - 2), dim_style);
            y += 1;
        }

        // === THINKING SECTION ===
        if self.thinking.is_some() && y < area.y + area.height - 2 {
            let sep = format!("├{}┤", "─".repeat(inner_width));
            buf.set_string(area.x, y, &sep, border_style);
            y += 1;

            buf.set_string(area.x, y, "│", border_style);
            buf.set_string(area.x + area.width - 1, y, "│", border_style);

            let thinking_header = format!(
                "THINKING {}",
                self.thinking_tokens.map(|t| format!("▼ {} tok", t)).unwrap_or_default()
            );
            buf.set_string(area.x + 2, y, &thinking_header, dim_style);
            y += 1;

            if self.expanded_thinking {
                if let Some(ref thinking) = self.thinking {
                    for line in thinking.lines().take(8) {
                        if y >= area.y + area.height - 3 {
                            break;
                        }
                        buf.set_string(area.x, y, "│", border_style);
                        buf.set_string(area.x + area.width - 1, y, "│", border_style);
                        buf.set_string(area.x + 2, y, format!("┊ {}", Self::truncate(line, inner_width - 4)), thinking_style);
                        y += 1;
                    }
                }
            } else {
                buf.set_string(area.x, y, "│", border_style);
                buf.set_string(area.x + area.width - 1, y, "│", border_style);
                buf.set_string(area.x + 2, y, "┊ [Click to expand reasoning trace]", dim_style);
                y += 1;
            }
        }

        // === NESTED CHILDREN SECTION ===
        if !self.children.is_empty() && y < area.y + area.height - 2 {
            let sep = format!("├{}┤", "─".repeat(inner_width));
            buf.set_string(area.x, y, &sep, border_style);
            y += 1;

            buf.set_string(area.x, y, "│", border_style);
            buf.set_string(area.x + area.width - 1, y, "│", border_style);
            buf.set_string(area.x + 2, y, format!("NESTED TASKS ({})", self.children.len()), dim_style);
            y += 1;

            if self.expanded_children {
                let max_children = match self.render_mode {
                    RenderMode::Compact => 2,
                    RenderMode::Expanded => 5,
                    RenderMode::Full => 10,
                };

                for (i, child) in self.children.iter()
                    .skip(self.children_scroll as usize)
                    .take(max_children)
                    .enumerate()
                {
                    let available_height = area.y.saturating_add(area.height)
                        .saturating_sub(y)
                        .saturating_sub(4);

                    let child_height = child.required_height().min(available_height).min(8);
                    if child_height < 4 || y + child_height >= area.y + area.height - 2 {
                        break;
                    }

                    // Indent for nested rendering
                    let child_area = Rect {
                        x: area.x + 2,
                        y,
                        width: area.width.saturating_sub(4),
                        height: child_height,
                    };

                    // Fill borders
                    for cy in y..y + child_height {
                        buf.set_string(area.x, cy, "│", border_style);
                        buf.set_string(area.x + area.width - 1, cy, "│", border_style);
                    }

                    // Highlight selected child
                    let is_selected = self.selected_child == Some(i + self.children_scroll as usize);
                    if is_selected {
                        // Could add selection highlight here
                    }

                    child.render(child_area, buf);
                    y += child_height;
                }

                // Show "+N more" if truncated
                let remaining = self.children.len().saturating_sub(max_children + self.children_scroll as usize);
                if remaining > 0 && y < area.y + area.height - 2 {
                    buf.set_string(area.x, y, "│", border_style);
                    buf.set_string(area.x + area.width - 1, y, "│", border_style);
                    buf.set_string(area.x + 2, y, format!("... +{} more tasks", remaining), dim_style);
                    y += 1;
                }
            } else {
                buf.set_string(area.x, y, "│", border_style);
                buf.set_string(area.x + area.width - 1, y, "│", border_style);
                buf.set_string(area.x + 2, y, format!("▶ {} nested tasks (press Enter to expand)", self.children.len()), dim_style);
                y += 1;
            }
        }

        // === ERROR SECTION ===
        if let Some(ref err) = self.structured_error {
            if y < area.y + area.height - 2 {
                let sep = format!("├{}┤", "─".repeat(inner_width));
                buf.set_string(area.x, y, &sep, border_style);
                y += 1;

                buf.set_string(area.x, y, "│", border_style);
                buf.set_string(area.x + area.width - 1, y, "│", border_style);
                buf.set_string(area.x + 2, y, "ERROR", error_style);
                y += 1;

                // Error message
                buf.set_string(area.x, y, "│", border_style);
                buf.set_string(area.x + area.width - 1, y, "│", border_style);
                buf.set_string(area.x + 2, y, format!("┊ ❌ Agent failed at turn {}", err.failed_turn), error_style);
                y += 1;

                // Cause
                if let Some(ref cause) = err.cause {
                    buf.set_string(area.x, y, "│", border_style);
                    buf.set_string(area.x + area.width - 1, y, "│", border_style);
                    buf.set_string(area.x + 2, y, format!("┊    Cause: {}", Self::truncate(cause, inner_width - 12)), dim_style);
                    y += 1;
                }

                // Last tool
                if let Some(ref tool) = err.last_tool {
                    buf.set_string(area.x, y, "│", border_style);
                    buf.set_string(area.x + area.width - 1, y, "│", border_style);
                    buf.set_string(area.x + 2, y, format!("┊    Last tool: {}", tool), dim_style);
                    y += 1;
                }

                // Hint
                if let Some(ref hint) = err.hint {
                    buf.set_string(area.x, y, "│", border_style);
                    buf.set_string(area.x + area.width - 1, y, "│", border_style);
                    buf.set_string(area.x + 2, y, format!("┊    Hint: {}", hint), dim_style);
                    y += 1;
                }
            }
        }

        // === FINAL RESPONSE SECTION ===
        if self.final_response.is_some() && y < area.y + area.height - 2 {
            let sep = format!("├{}┤", "─".repeat(inner_width));
            buf.set_string(area.x, y, &sep, border_style);
            y += 1;

            buf.set_string(area.x, y, "│", border_style);
            buf.set_string(area.x + area.width - 1, y, "│", border_style);
            buf.set_string(area.x + 2, y, "FINAL RESPONSE", dim_style);
            y += 1;

            if let Some(ref response) = self.final_response {
                let max_lines = if self.expanded_response { 15 } else { 3 };
                for line in response.lines().take(max_lines) {
                    if y >= area.y + area.height - 1 {
                        break;
                    }
                    buf.set_string(area.x, y, "│", border_style);
                    buf.set_string(area.x + area.width - 1, y, "│", border_style);
                    buf.set_string(area.x + 2, y, format!("┊ {}", Self::truncate(line, inner_width - 4)), content_style);
                    y += 1;
                }

                if !self.expanded_response && response.lines().count() > max_lines {
                    buf.set_string(area.x, y, "│", border_style);
                    buf.set_string(area.x + area.width - 1, y, "│", border_style);
                    buf.set_string(area.x + 2, y, "┊ [truncated, press Enter to expand]", dim_style);
                    y += 1;
                }
            }
        }

        // === TIMING FOOTER (Expanded mode) ===
        if matches!(self.render_mode, RenderMode::Expanded | RenderMode::Full) {
            if y < area.y + area.height - 2 {
                let sep = format!("├{}┤", "─".repeat(inner_width));
                buf.set_string(area.x, y, &sep, border_style);
                y += 1;
            }

            if y < area.y + area.height - 1 {
                buf.set_string(area.x, y, "│", border_style);
                buf.set_string(area.x + area.width - 1, y, "│", border_style);

                let total = self.duration_ms.map(|d| format!("{:.1}s", d as f64 / 1000.0))
                    .unwrap_or_else(|| "—".to_string());
                let avg = self.avg_turn_duration_ms()
                    .map(|d| format!("{:.1}s", d as f64 / 1000.0))
                    .unwrap_or_else(|| "—".to_string());

                let timing = format!(
                    "⏱️  Total: {} │ Avg/turn: {} │ Depth: {}",
                    total, avg, self.depth
                );
                buf.set_string(area.x + 2, y, Self::truncate(&timing, inner_width - 2), metric_style);
                y += 1;
            }
        }

        // === FILL REMAINING ===
        while y < area.y + area.height - 1 {
            buf.set_string(area.x, y, "│", border_style);
            buf.set_string(area.x + area.width - 1, y, "│", border_style);
            y += 1;
        }

        // === BOTTOM BORDER ===
        let bottom = format!("╰{}╯", "─".repeat(inner_width));
        buf.set_string(area.x, area.y + area.height - 1, &bottom, border_style);
    }
}
```

```rust
impl AgentBox {
    /// Export to JSON for clipboard/logging
    pub fn to_json(&self) -> serde_json::Value {
        let mut json = serde_json::json!({
            "task_id": self.task_id,
            "prompt": self.prompt,
            "turn": self.turn,
            "max_turns": self.max_turns,
            "depth": self.depth,
            "state": self.state.label(),
        });

        if let Some(ref provider) = self.provider {
            json["provider"] = serde_json::json!(provider);
        }

        if let Some(ref model) = self.model {
            json["model"] = serde_json::json!(model);
        }

        json["tokens"] = serde_json::json!({
            "input": self.tokens_in,
            "output": self.tokens_out,
            "thinking": self.thinking_tokens,
        });

        json["cost"] = serde_json::json!(self.cost);
        json["tool_calls"] = serde_json::json!(self.tool_calls);
        json["mcp_servers"] = serde_json::json!(self.mcp_servers);

        // Children (recursive)
        let children_json: Vec<serde_json::Value> = self.children.iter()
            .map(|c| match c {
                TaskBox::Infer(b) => b.to_json(),
                TaskBox::Exec(b) => b.to_json(),
                TaskBox::Fetch(b) => b.to_json(),
                TaskBox::Invoke(b) => b.to_json(),
                TaskBox::Agent(b) => b.to_json(),
            })
            .collect();
        json["children"] = serde_json::json!(children_json);

        if let Some(ref response) = self.final_response {
            json["final_response"] = serde_json::json!(response);
        }

        if let Some(ref err) = self.structured_error {
            json["error"] = serde_json::json!({
                "message": err.message,
                "failed_turn": err.failed_turn,
                "cause": err.cause,
                "last_tool": err.last_tool,
                "hint": err.hint,
            });
        }

        if let Some(duration) = self.duration_ms {
            json["duration_ms"] = serde_json::json!(duration);
        }

        json
    }

    /// Get keyboard shortcuts for this widget
    pub fn keyboard_shortcuts() -> &'static [(&'static str, &'static str)] {
        &[
            ("Enter", "Toggle response expansion"),
            ("t", "Toggle thinking section"),
            ("c", "Toggle children section"),
            ("j/k", "Navigate children (down/up)"),
            ("l", "Enter selected child"),
            ("h", "Exit to parent"),
            ("y", "Copy final response"),
            ("Y", "Copy full JSON (recursive)"),
            ("r", "Retry failed agent"),
            ("x", "Cancel running agent"),
            ("Esc", "Collapse all sections"),
        ]
    }
}
```

```rust
fn bench_agent_render_compact(c: &mut Criterion) {

fn bench_agent_cost_calculation(c: &mut Criterion) {
    let mut box_ = AgentBox::new("task")
        .with_tokens(10000, 5000);

    for _ in 0..5 {
        let child = AgentBox::new("subtask").with_tokens(2000, 1000);
        box_.add_child(child);
    }

    c.bench_function("agent_cost_total", |b| {
        b.iter(|| {
            black_box(box_.total_cost());
        })
    });
}

fn bench_agent_to_json_recursive(c: &mut Criterion) {
    let mut box_ = AgentBox::new("root");
    for i in 0..5 {
        let mut child = AgentBox::new(&format!("child_{}", i));
        for j in 0..3 {
            child.add_child(InvokeBox::new(&format!("tool_{}_{}", i, j), "server"));
        }
        box_.add_child(child);
    }

    c.bench_function("agent_to_json_recursive", |b| {
        b.iter(|| {
            black_box(box_.to_json());
        })
    });
}
```
