**Release Date:** February 23, 2026
**Status:** Production Ready

## Overview

Nika v0.8.0 marks the transition from MVP to production-grade TUI (Terminal User Interface). This release focuses on **stability, user experience, and persistence** — turning the Nika TUI from a powerful prototype into a professional workflow tool.

Key achievement: **8 phases of production improvements** delivering edit history, session persistence, theming, and robust error handling.

---

## Major Features

### 1. Edit History (Undo/Redo)

Full undo/redo support for all TUI operations — a critical feature for workflows that may run for hours.

**Features:**
- **Undo**: `Ctrl+Z` — Revert last change
- **Redo**: `Ctrl+Y` (or `Ctrl+Shift+Z`) — Restore undone change
- **History Buffer**: In-memory stack with configurable size limit (default: 100 operations)
- **Deep Cloning**: Each operation captures full state for safe recovery
- **Operation Types Supported**:
  - Text edits (YAML studio view)
  - View/tab navigation
  - Workflow parameter changes
  - Chat message composition

**Implementation:**
- `tui/history.rs` (165 lines) — History trait + Stack struct
- `tui/app.rs` — Integration with App state machine
- `event/log.rs` — `HistoryChange` event type for observability
- Tests: 28 tests in `tests/history_test.rs`

**Use Cases:**
```
1. Accidentally delete workflow definition → Ctrl+Z → Restored
2. Change parameter three times → Ctrl+Z, Ctrl+Z, Ctrl+Z → Back to original
3. Realize you wanted the second option → Ctrl+Y → Return to it
```

### 2. Session Persistence

Save and restore TUI sessions — users can exit and resume mid-workflow without losing context.

**Features:**
- **Session Directory**: `~/.nika/sessions/` with one JSON file per session
- **Auto-Save**: Every 30 seconds or after significant changes (configurable)
- **Session Recovery**: On startup, offer to restore last session
- **State Captured**:
  - Active workflow file and line number
  - Tab history and current view
  - Workflow parameters
  - Chat message history
  - Editor cursor position and scroll offset

**File Format:**
```json
{
  "id": "session-abc123",
  "created": "2026-02-23T14:32:00Z",
  "last_modified": "2026-02-23T15:45:30Z",
  "active_file": "/path/to/workflow.nika.yaml",
  "current_view": "studio",
  "active_tab": 2,
  "tabs": [
    { "path": "workflow1.yaml", "line": 42, "scroll": 120 },
    { "path": "workflow2.yaml", "line": 1, "scroll": 0 }
  ],
  "editor_state": {
    "cursor_row": 15,
    "cursor_col": 8,
    "scroll_offset": 120
  },
  "chat_history": [
    { "role": "user", "content": "Generate..." },
    { "role": "assistant", "content": "..." }
  ],
  "parameters": {
    "provider": "claude",
    "model": "claude-opus-4-5-20251101"
  }
}
```

**Implementation:**
- `core/session.rs` (312 lines) — Session struct + persistence logic
- `tui/app.rs` — Session recovery on startup
- `event/log.rs` — `SessionSaved` / `SessionRestored` events
- Tests: 42 tests in `tests/session_persistence_test.rs`

**User Flow:**
1. Start Nika, work for 2 hours
2. `Ctrl+Q` to quit — session auto-saved
3. Next day: `nika` → "Restore session from 2026-02-23 15:45:30? (y/n)"
4. Hit `y` → All context restored, continue from line 42

### 3. Solarized Theme

Professional color scheme for extended TUI sessions — reduces eye strain and improves readability in different lighting conditions.

**Features:**
- **Three Themes**:
  - `Dark` (default) — Deep space palette (existing)
  - `Light` — Solarized light background with dark text
  - `Solarized` — Solarized dark (true warm blacks, accent colors)
- **Theme Colors** (all 16-color terminal compatible):
  - Base colors (background, text)
  - Accent palette (cyan, blue, magenta, red, orange, yellow, green)
  - Status colors (success=green, warn=yellow, error=red, info=blue)
- **Theme Switching**: `Ctrl+T` to cycle through themes (in-session)
- **Persistent Selection**: Theme choice saved to `~/.nika/config.toml`

### 4. Config System

Centralized configuration file for all user preferences — no more environment variables or magic defaults.

**Features:**
- **Config File**: `~/.nika/config.toml` (TOML format, human-editable)
- **Settings Covered**:
  - TUI theme (dark/light/solarized)
  - Default LLM provider and model
  - Session auto-save interval (seconds)
  - History buffer size
  - MCP server connection timeout
  - Font size (terminal agnostic hints)
  - Log level (error/warn/info/debug/trace)
- **Auto-Create**: On first run, generates config with sensible defaults
- **Hot Reload**: Changes detected and applied without restart (for theme/log level)
- **Validation**: Invalid config values reported with helpful error messages

**Default Config:**
```toml
[tui]
theme = "dark"                    # dark | light | solarized
session_auto_save_interval_secs = 30
history_buffer_size = 100
font_size_hint = "auto"           # auto | small | medium | large

[llm]
default_provider = "claude"       # claude | openai | mistral | groq | deepseek | ollama
default_model = "claude-opus-4-5-20251101"

[mcp]
connection_timeout_secs = 10
retry_attempts = 3

[logging]
level = "info"                    # error | warn | info | debug | trace
format = "compact"                # compact | verbose
```

**Implementation:**
- `core/config.rs` (280 lines) — Config struct + TOML serialization
- `core/config_builder.rs` (145 lines) — Builder pattern for defaults
- `tui/app.rs` — Config loading and hot reload
- `event/log.rs` — `ConfigLoaded` / `ConfigReloaded` events
- Tests: 38 tests in `tests/config_test.rs`

**User Flow:**
1. First run: `nika` → Creates `~/.nika/config.toml` with defaults
2. Edit: `vim ~/.nika/config.toml` → Change `theme = "solarized"`
3. Switch views in Nika → Theme automatically updates (no restart)
4. Next launch: Solarized theme remembered

## Migration & Compatibility

### Backward Compatibility ✅

Nika v0.8.0 is **100% backward compatible** with v0.7.x:

- **Workflows**: All existing `.nika.yaml` files work unchanged
- **CLI**: All commands (`nika run`, `nika chat`, `nika studio`) behave identically
- **MCP**: No MCP protocol changes; existing integrations continue working
- **Config**: Optional — users can run without `config.toml`; defaults apply

### Auto-Migration

On first v0.8.0 launch:

1. Creates `~/.nika/` directory (if missing)
2. Generates `config.toml` with sensible defaults
3. Offers to restore previous session (if exists from v0.7.x)
4. Uses Dark theme by default (preserving visual continuity)

**No manual migration steps required.**

### Breaking Changes

**None.** This is a pure addition release.

## Known Limitations & Roadmap

### Current Limitations (v0.8.0)

1. **History Buffer**: In-memory only (cleared on restart) — persistent undo planned for v1.0
2. **Theme Scope**: Terminal colors only — does not affect font rendering
3. **Config Format**: TOML only — YAML format planned for v0.9
4. **Session Limit**: Max 50 concurrent sessions (oldest auto-pruned)

### Future Enhancements (v0.9+)

- [ ] Persistent undo history (SQLite backend)
- [ ] YAML config file option
- [ ] Custom theme editor (interactive palette picker)
- [ ] Config profiles (e.g., "dark-fast", "light-slow")
- [ ] Session sync across machines

## Appendix: Configuration Reference

### Full Config Schema

```toml
[tui]
# Theme: dark, light, or solarized
theme = "dark"

# Auto-save session every N seconds
session_auto_save_interval_secs = 30

# Maximum undo/redo operations in history
history_buffer_size = 100

# Terminal font size hint (informational only)
font_size_hint = "auto"

# Show help on startup (first run only)
show_help_on_startup = true

[llm]
# Default LLM provider for nika chat
default_provider = "claude"

# Default model for the provider
default_model = "claude-opus-4-5-20251101"

[mcp]
# Timeout for MCP server connections (seconds)
connection_timeout_secs = 10

# Retry attempts for failed MCP calls
retry_attempts = 3

# MCP server ports (space-separated, default: auto)
server_ports = ""

[logging]
# Log level: error, warn, info, debug, trace
level = "info"

# Log format: compact or verbose
format = "compact"

# Log file location (if empty, logs to stderr only)
file = ""

[editor]
# Tab width (spaces)
tab_width = 2

# Enable line numbers
show_line_numbers = true

# Word wrap at N characters (0 = disable)
word_wrap_width = 0
```
