## Phase 1: Critical Wiring Fixes (P0)

### 1.1 Wire Session Persistence to App
**File:** `src/tui/app.rs`
**Issue:** `src/tui/session.rs` module exists but never imported/used
**Fix:**
```rust
// In App struct
session_manager: SessionManager,

// In App::new()
let session_manager = SessionManager::new()?;
let session = session_manager.load_latest()?;

// On quit
self.session_manager.save(&self.current_session())?;
```
**Tests:** 3 integration tests for save/load/restore

**Tests:** 3 tests for config load/save/defaults

### 1.3 Fix Settings Theme Selection
**File:** `src/tui/views/settings.rs:307-310`
**Issue:** Keys [1][2][3] all return `ViewAction::ToggleTheme` instead of selecting specific theme
**Fix:**
```rust

KeyCode::Char('2') => ViewAction::SetTheme(Theme::Dark),
KeyCode::Char('3') => ViewAction::SetTheme(Theme::Solarized),
```

**Requires:** New `ViewAction::SetTheme(Theme)` variant
**Tests:** 3 tests for each theme selection

### 1.4 Wire Log Event Emission
**File:** `src/runtime/builtin/log.rs:144-151`
**Issue:** Only calls `tracing::*!()`, never emits `EventKind::Log`
**Fix:**
```rust
// After tracing call
if let Some(ref event_log) = self.context.event_log {
    event_log.emit(EventKind::Log {
        level: level.to_string(),
        message: params.message.clone(),
        task_id: self.context.task_id.clone(),
    });
}
```
**Requires:** Add `event_log: Option<Arc<EventLog>>` to BuiltinToolContext
**Tests:** 2 tests for log emission

### 1.5 Wire Custom Event Emission
**File:** `src/runtime/builtin/emit.rs:119`

**Fix:**

**Tests:** 2 tests for custom event emission
