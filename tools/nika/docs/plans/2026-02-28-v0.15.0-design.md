## 1. Security: Shell-Free by Default

### Problem

Command injection via unsanitized template interpolation in `exec:` verb:

```yaml
exec: "echo {{use.user_input}}"
# If user_input = "hello; rm -rf /" → INJECTION!
```

### Solution (CISA-Compliant)

**Tier 1: Shell-Free Mode (Default for templated commands)**

```rust
// Before: shell interpretation
std::process::Command::new("sh")
    .arg("-c")
    .arg(format!("echo {}", user_input))

// After: parameterized (no shell)
std::process::Command::new("echo")
    .arg(user_input)  // Safe, no shell metachar interpretation
```

**Tier 2: Explicit Shell (Opt-in)**

```yaml
exec:
  command: "echo $HOME && ls | grep foo"
  shell: true  # User takes responsibility
```

When `shell: true` + templates: use `shlex::try_quote()` for escaping.

**Tier 3: Defense in Depth (Always on)**

- Reject control characters (0x00-0x1F except \n\t)
- Blocklist: `rm -rf /`, `curl|bash`, `eval`, `mkfifo`, `nc -e`
- New error: `NIKA-050 CommandInjectionBlocked`

### Files to Modify

|------|---------|
| `Cargo.toml` | Add `shlex = "1.3"` |
| `src/ast/action.rs` | Add `shell: Option<bool>` to ExecParams |

| `src/runtime/executor.rs` | Implement shell-free execution logic |

## 2. Infer: temperature + system + max_tokens

### Problem

`infer:` verb lacks LLM control parameters that `agent:` has:

| Feature | agent: | infer: |
|---------|--------|--------|
| temperature | ✅ | ❌ |
| system | ✅ | ❌ |
| max_tokens | ✅ (8192) | ❌ (hardcoded) |

### Solution

Extend `InferParams` with optional fields:

```yaml
# New syntax
infer:
  prompt: "Generate a tagline"
  temperature: 0.9
  system: "You are a creative copywriter"
  max_tokens: 1000
```

### Files to Modify

| File | Changes |
|------|---------|
| `src/ast/action.rs` | Add fields to InferParams + deserializer |
| `schemas/nika-workflow.schema.json` | Add properties to InferParams |
| `src/provider/rig.rs` | New `infer_with_options()` method |
| `src/runtime/executor.rs` | Pass options to provider |

### Implementation

```rust
// src/ast/action.rs
pub struct InferParams {
    pub prompt: String,
    pub provider: Option<String>,
    pub model: Option<String>,
    pub temperature: Option<f32>,      // NEW
    pub system: Option<String>,        // NEW
    pub max_tokens: Option<u32>,       // NEW
}

// src/provider/rig.rs
pub async fn infer_with_options(
    &self,
    prompt: &str,
    model: Option<&str>,
    temperature: Option<f32>,
    system: Option<&str>,
    max_tokens: Option<u32>,
) -> Result<String, RigInferError>
```
