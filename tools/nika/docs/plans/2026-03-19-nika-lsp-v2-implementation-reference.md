## 1. FileSnapshot — Zero-Lifetime DashMap Access

The WorldDatabase uses DashMap internally. Handlers must NOT hold DashMap guards.
Solution: `FileSnapshot` owns `Arc` clones — O(1) to create, no lifetime parameters.

```rust
/// Snapshot of a single file's analysis state.
/// Everything is Arc-wrapped or Copy — cloning is O(1).
/// This is what handlers receive. No DashMap guard lifetimes leak.
#[derive(Debug, Clone)]
pub struct FileSnapshot {
    pub text: Arc<str>,
    pub line_index: Arc<LineIndex>,
    pub position_index: Arc<PositionIndex>,
    pub parsed: Option<Arc<ParsedDocument>>,
    pub analyzed: Option<Arc<AnalyzedSnapshot>>,
    pub partial: Option<Arc<PartialWorkflow>>,  // from tree-sitter (broken YAML)
    pub revision: u64,
}

impl WorldDatabase {
    /// Take a consistent snapshot. O(1) Arc clones per field.
    /// DashMap guards dropped immediately.
    pub fn snapshot(&self, file: FileKey) -> Option<FileSnapshot> {
        let (text, rev) = {
            let entry = self.texts.get(&file)?;
            (Arc::clone(&entry.0), entry.1)
        };
        let line_index = self.line_indices.get(&file)
            .map(|v| Arc::clone(&v.value))
            .unwrap_or_else(|| Arc::new(LineIndex::new(&text)));
        let position_index = self.position_indices.get(&file)
            .map(|v| Arc::clone(&v.value));
        let parsed = self.parsed.get(&file).map(|v| Arc::clone(&v.value));
        let analyzed = self.analyzed.get(&file).map(|v| Arc::clone(&v.value));
        let partial = self.partials.get(&file).map(|v| Arc::clone(&v.value));

        Some(FileSnapshot {
            text, line_index,
            position_index: position_index.unwrap_or_else(|| Arc::new(PositionIndex::empty())),
            parsed, analyzed, partial, revision: rev,
        })
    }
}
```

## 2. PositionIndex — O(log n) Node-at-Offset Lookup

Sorted Vec with binary search. Not an interval tree (YAML spans don't heavily overlap).

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SpanKind {
    Schema,
    WorkflowName,
    Task(String),
    Verb { task_id: String, verb: String },
    WithBlock { task_id: String },
    WithBinding { task_id: String, alias: String },
    ForEach { task_id: String },
    McpServer(String),
    ContextFile(String),
    Import { path: String },
    Content { task_id: String },
    Template { task_id: String, expr: String },
    Guardrails { task_id: String },
    DependsOn { task_id: String },
}

#[derive(Debug, Clone)]
pub struct SpanEntry {
    pub start: u32,
    pub end: u32,
    pub kind: SpanKind,
}

#[derive(Debug, Clone)]
pub struct PositionIndex {
    entries: Vec<SpanEntry>,  // sorted by (start ASC, span_length ASC)
}

impl PositionIndex {
    pub fn build(workflow: &AnalyzedWorkflow) -> Self {
        let mut entries = Vec::with_capacity(workflow.tasks.len() * 3 + 8);
        // ... populate from workflow spans ...
        entries.sort_unstable_by(|a, b| {
            a.start.cmp(&b.start)
                .then_with(|| (a.end - a.start).cmp(&(b.end - b.start)))
        });
        Self { entries }
    }

    /// O(log n) binary search + O(k) scan where k = nesting depth (~2-3).
    pub fn context_at(&self, offset: u32) -> Option<&SpanEntry> {
        let idx = self.entries.partition_point(|e| e.start <= offset);
        let mut best: Option<&SpanEntry> = None;
        let mut best_len = u32::MAX;
        for entry in self.entries[..idx].iter().rev() {
            if entry.end <= offset { continue; }
            let len = entry.end - entry.start;
            if len < best_len { best_len = len; best = Some(entry); }
        }
        best
    }
}
```

## 5. AnalysisScheduler — Debouncing + Cancellation

```rust
pub struct AnalysisScheduler {
    edit_notify: Arc<Notify>,
    cancel: Arc<RwLock<CancellationToken>>,
    debounce: Duration,
}

impl AnalysisScheduler {
    pub fn new(debounce: Duration) -> Self { /* ... */ }
    pub fn notify_edit(&self) { self.edit_notify.notify_one(); }

    pub fn spawn<F, Fut>(&self, analyze_fn: F) -> JoinHandle<()>
    where F: Fn(CancellationToken) -> Fut + Send + Sync + 'static,
          Fut: Future<Output = ()> + Send,
    {
        let notify = Arc::clone(&self.edit_notify);
        let cancel = Arc::clone(&self.cancel);
        let debounce = self.debounce;
        tokio::spawn(async move {
            loop {
                notify.notified().await;
                // Debounce: reset on rapid edits
                loop {
                    tokio::select! {
                        _ = tokio::time::sleep(debounce) => break,
                        _ = notify.notified() => continue,
                    }
                }
                // Cancel in-flight, swap token
                { let mut g = cancel.write().await; g.cancel(); *g = CancellationToken::new(); }
                let token = cancel.read().await.clone();
                analyze_fn(token).await;
            }
        })
    }
}
```

Integration with tower-lsp:
- `did_change` → `scheduler.notify_edit()` (non-blocking)
- `completion/hover` → `db.snapshot(file)` (O(1), uses cached data)
- Background loop → `db.analyze_file(file, &cancel_token)` → `client.publish_diagnostics()`

## 7. Handler Signature Pattern

```rust
// nika-lsp-core: pure function, no async, no ls-types
pub fn completions(snapshot: &FileSnapshot, position: TextPosition) -> Vec<CompletionEntry> {
    let offset = snapshot.line_index.offset_of(position);
    let context = detect_context(snapshot, offset);
    match context {
        CursorContext::WorkflowRoot { prefix } => workflow_root_completions(&prefix, snapshot),
        CursorContext::Template { in_transform_chain: true, partial_expr, .. } =>
            transform_completions(&partial_expr),
        CursorContext::DependsOn { existing_deps, prefix, .. } =>
            depends_on_completions(&prefix, &existing_deps, snapshot),
        // ... dispatch all 16 variants
        CursorContext::Unknown { .. } => Vec::new(),
    }
}

// nika (binary): thin async shim
async fn completion(&self, params: CompletionParams) -> Result<Option<CompletionResponse>> {
    let snapshot = self.db.snapshot(file_key)?;
    let position = TextPosition::from(params.text_document_position.position);
    let items = nika_lsp_core::handlers::completions(&snapshot, position);
    Ok(Some(CompletionResponse::Array(items.into_iter().map(Into::into).collect())))
}
```
